## What 1.6 already is

1.6 is the engine release: everything a document computes now runs on Solenoid's own Rust
core, in WebAssembly ([[C130]] rustCore). Built and on `develop` since the v1.5.0 tag:

- **One engine, in Rust.** The TypeScript engine, Polars and rete are gone; the graph runs on
  netcore-rs; card bodies run on the core; exact sums; linear work at 800k rows; cards held to
  their formulas (171 pairs) and Excel answers checked in the author's Excel.
- **Dates are a value kind** ([[D114]] dateIsAKind, [[C137]] datesNeverSerials): never a
  serial outside Cast; every card takes dates. InlineCast on the Formula card ([[D113]]).
- **Wildcards typed by their values** ([[D117]], [[C136]] typesKnownAfterCalc).
- **New cards and views:** Pivot view and Pivot Details, Choice Ladder, Dashboard node (and on
  a phone), Cards as its own card, Record's figure in the card, XLookup with Filter's modes,
  XY annotations (date x, References, log y).
- **The Navigator as a workspace tree** ([[C132]] workspaceTree), composite drill-in on a phone.
- **One file and folder picker** (`FilePicker`, the OS dialog on desktop).
- **Safe to share** ([[B18]]): a foreign document's scripts and web images wait for a grant.
- **Obsidian:** Write to Obsidian writes Solenoid Properties types ([[D116]]).
- **Android:** prepared and running on the author's phone with granted folders (`android.md`).
- **Headless CLI** (`npm run build:cli`), unpublished.

## 3 — Later (no version; stays in the backlog or moves)

**Stays in the backlog, unversioned**

- *Canvas frame cost* (zoom re-record, pan layerize, bead overlay, XPS/WebKitGTK measurement):
  research items, low priority by the author's word.
- *Performance:* `raw` text memory, double serialization per edit, undo rebuilding the graph.
- *Rust core:* layering the core into five groups, INTERPOLATE's grid fill.
- *Tooling:* interim upstream PRs, relative-date wording, regex recursion, chrono-node repo,
  ISNULL vs ISBLANK, dead CSS, glossary process names, renumber the tree (after ratification),
  IronCalc oracle, scroll hand-off app-wide, Report embed view choice.
- *Headless CLI publishing* (npm, `--set`, `--out`, the GitHub Action example), unless the
  author wants it as a 1.6 headliner.
- *Formula library:* Equation answering any type, the settings sweep, missing card options,
  the other merges, functions short of Excel's signature, Cube Input λ inputs, a list read as
  a column.
- *Units:* temperature differences and mixing ([[C25]], two leaf breaks), cards that strip
  units, socket labels losing parentheses, units in column headers, pack units, preset units.
- *Schedule:* working-day durations, Project-exported goldens (author).
- *Canvas chrome:* custom logomarks, the app's own tooltip, WebKitGTK dots, Surface rotation in
  a Display, collapsed-card stragglers, the collapsed pill listing every cable, phone
  landscape checks, the hand-tidy drift.
- *Frame popup:* nested cell previews in Cards, footer pills, the λ highlighter, Pivot view
  follow-ups.
- *Script:* the Python option (an open question, not a plan).
- *JavaScript wording leftovers* and a case setting for text ordering.
- *Rest of the Recharts list.*
