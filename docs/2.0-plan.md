# Solenoid 2.0 — release plan (author-present flagships)

The genuinely-major arcs reserved for 2.0, each built WITH the author in a dedicated
session (decided 2026-07-06, organized 2026-07-08). Bundle-level detail lives in
[`v2.0/`](v2.0/README.md); this is the release view. 1.2's incremental queue is
[`1.2-plan.md`](1.2-plan.md).

## The flagships, in intended order

1. **FC A4 — units by dimensionality** (`v2.0/05`). Per-element list units, per-column
   frame units, FC-tagged header keys locking Build Frame columns; matrices stay
   unit-agnostic. The representation is decided (tagged cells) and the `dimension.ts`
   algebra core is landed. The author's "big boy": build together.
2. **Excel `.xlsx` transpiler** (`v2.0/08`). The import story: a workbook becomes a
   graph. Deliberately sequenced late; not started.
3. **D2 — toolbar reroute** for the composite drill-in. The real top toolbar and mobile
   bar drive the active subgraph; finishes the first-class drill-in arc. Cross-cutting,
   wants live eyeballing.
4. **D4 — conditional formatting for tables.** Needs its own design pass; the author's
   bar is that it must clear Excel's version by a lot. Display-node-only; must not step
   on FC format/units territory.

## Gated bundles

- **Monte Carlo run-mode hook** — the gate for `v2.0/10` (decision sensitivity:
  "wiggle the weights") and half of `v2.0/12`.
- **`v2.0/12` value-model extensions** — uncertain values + money mode; each needs an
  author representation call first. The as-of half already shipped in 1.1.
