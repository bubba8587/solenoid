# Solenoid 1.2 — release plan (the post-1.1 queue)

Everything deferred past the 1.1 tag that is NOT a 2.0 flagship (those live in
[`2.0-plan.md`](2.0-plan.md)). Organized 2026-07-08 from the author's defer calls.
`backlog.md` stays the working queue; reconcile this the same way (delete lines as
they land). Most items here are autonomous-friendly; author gates are marked.

## Theme

1.1 shipped the feature body; 1.2 is the polish-and-close release: fix the known
rough edges, finish the half-built tails, and round out the what-if/data stories.

## Tier 1 — known-issue fixes (the release's backbone; all shipped in 1.1's Known Issues list)

- [ ] **Tidy / Cleanup around expanded groups is wonky** (author-reported). Auto-arrange
  and cleanup can misplace nodes when expanded groups are involved. Root-cause pass over
  the group-footprint handling in the arrange path (ELK reserve-footprint + docked-FC
  re-snap + group push interplay). The one item here that needs real investigation.
- [x] **Node-label edits aren't undoable** — RESOLVED IN CODE (stale item, 2026-07-10
  audit). The premise "it never went through pushHistory" is no longer true: the node
  title is the only label-edit surface (no other rename UI exists), it commits via
  `useDraftCommit`, and `useDraftCommit.onBlur` gained `pushHistory(() => apply(committed),
  () => apply(next))` on 2026-07-08 (after the 2026-07-07 note) — routed through
  `getActiveHistory`, so it undoes on the main canvas AND inside a drill-in. Needs only an
  author UI eyeball to confirm the re-render/propagation; if good, drop it from
  `release-notes-features.md`'s Known Issues (line ~164).
- [x] **Private-browsing reload loop** on a stale deploy during an outage — DONE
  2026-07-10. (Corrected the plan: an in-memory fallback can't work — a reload wipes
  memory. The `vite:preloadError` guard now FAILS SAFE: it reloads only when the
  sessionStorage timestamp can actually be persisted, else surfaces the error. Logic
  extracted to `chunkReloadGuard.ts` + unit-tested.)
- [x] **Set nodes compare complex numbers by identity** — DONE 2026-07-10: a shared
  `setKey()` canonicalizes a complex `[re, im]` tuple to a string across SetOp / Is In /
  Tally / Set relation (primitives unchanged). (Tally's frame Value column still
  stringifies complex — frames have no complex type — but the count groups by value.)
- [ ] **Problems panel + model fuzzer miss per-cell errors** inside lists/frames — needs a
  bounded scan strategy (sample or cap per pass; full-cell scans were rejected on perf).

## Tier 2 — finish the half-built tails (deferred 2026-07-08)

- [ ] **F-2 remainder** — a UI to edit per-slot doc-palette overrides (store half exists:
  `paletteStore.setDocPalette` overrides already round-trip) + document-level FC defaults.
- [x] **D-2 simulation inner display** — DONE 2026-07-12 (Stream C). The Simulation
  output series renders as a sparkline (above its list chip) INSIDE the drill-in output
  marker AND on the composite card (`MiniSparkline`, numeric-series-gated).
- [x] **Goal-seek solver parameters** — DONE 2026-07-12 (Stream C). Optional
  `maxIterations` / `tolerance` / `boundsLo` / `boundsHi` on `CompositeGoalSeek`
  (undefined = built-in defaults, so the round-trip test is unaffected); `solveGoalSeek`
  honors them (bounds clamp the search + bisect the window directly); surfaced in
  `GoalSeekEditor`'s FC-style chip-foot advanced tier.
- [x] **Composite run-mode seeds** — DONE 2026-07-12 (Stream C). Added Monte Carlo,
  Scenarios, and Data Table cards to the Composite Workbench seed (each note + composite +
  display), covered by `compositeSeed.test.ts`.
- [x] **Monte Carlo run mode + uncertainty values** — DONE 2026-07-12 (Stream C). New
  `montecarlo` composite run mode: composite input markers carry an optional `± spread`
  + normal/uniform distribution (drill-in-only authoring); a seeded sampler
  (`monteCarlo.ts`, deterministic mulberry32) draws N times and summarizes each output as
  an `UncertainNumber` (`valueKinds.ts`, mean ± sd + histogram). Sample count + seed in
  the advanced tier. SCOPED to composites (author call) — NOT threaded through app-wide
  arithmetic. See dev-notes 2026-07-12.
- [ ] **Drill-in: the remaining main-only subsystems** — Group/Cleanup/Autofit/Expand +
  Isolate, then navigator + lasso, taught the active-graph seam. (The top-toolbar reroute
  D2 itself stays a 2.0 author-present item.)
