Writing a page

This page is one. It reads pages/guide.html and pages/guide.css from the data folder, and every value on it comes from the graph.

The page is only the last layer. The work (an import, a filter, a join, a chart) stays on the canvas as cards you can see and change, and the page lays out what they answer, so keep the logic in the graph and let the page format and place.

1 A tag is an input

Every name in a tag becomes a socket on the card, in the order the page first uses them. This page reads {{ greeting }} from a Value card.

<p>{{ greeting }}</p>

A tag on its own draws the value the way the canvas does, in its Format Controller's format: {{ price }}. A tag with a filter prints text you shape yourself: ${{ price | number_format: 2 }}, {{ greeting | upper }}.

{{ price }}   {{ price | number_format: 2 }}   {{ greeting | upper }}

Inside an attribute a tag always prints as text, so a value can size or color the markup itself. This bar is {{ progress }}% across:

<div class="meter"><i style="width: {{ progress }}%"></i></div>

2 Loops and ifs build the markup

A Frame wired in is rows to loop over; each column is a field. Knap's where, sort, map, sum and length work on it too: these {{ planets | length }} planets have {{ planets | map: "Moons" | sum }} moons between them.

{% for p in planets | sort: "Moons" | reverse %}
{{ p.Planet }}{{ p.Moons }} moons
{% endfor %} 
{% for p in planets | sort: "Moons" | reverse %}
  <div class="planet {% if p.Moons > 20 %}many{% endif %}">{{ p.Planet }}</div>
{% endfor %}

Knap drops the space just before a tag, so put it outside: class="planet {% if … %}many", not class="planet{% if … %} many".

3 Figures draw as boxes

A chart, table, diagram, picture or document on its own tag draws as a Dashboard box, at the page's width, live as the graph changes.

{{ moons }}

4 Style it like any page

The stylesheet only reaches this page. The app's own variables are yours to set, and figures read them from where they draw:

--surface --text --bordera box's ground, ink and edges
--font-sans --font-monoa chart's and a table's type
--chart-1 … --chart-12the series colors
--chart-font-scalea chart's text size
.sol-box .sol-box__label .sol-box__titlea box, its name bar, a figure's own title
[data-sol-ref="moons"]one value's slot, to style one box
@media (prefers-color-scheme: light)the app's light theme, not the system's: switch the app's theme and this page follows

5 Your own pictures and fonts

Name them as a web page would, relative to the file that names them: <img src="images/kiln-mark.svg">, url(fonts/Fraunces.woff2). The card reads each from the data folder and puts it inline, so nothing is fetched. This heading is set in Fraunces, read from pages/fonts:

Fraunces, from the vault

6 The rules

  • Scripts never run: a page is a document, not an app.
  • Nothing reaches the web. Pictures and fonts come from the data folder, up to 8 MB each.
  • A link to #id scrolls the page. Print saves it as a PDF.
  • Refresh reads the files again after you edit them.
