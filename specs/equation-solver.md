# Spec: Equation solver

Serves [[C47]] equationNode. The mechanics a builder implements: what the system does and blocks, with the decision each behaviour serves. Lifted from `docs/subsystem-invariants.md` § Equation solver; a WHY that is not in a node belongs in one.

Rearranges `LHS = RHS` for whichever variable is unknown, in two layers. (1) **Symbolic isolation** over the formula AST — when the unknown appears exactly once, walk down to it inverting each step (+−×÷^, EXP/LN, trig, SQRT…). The result is a NEW FORMULA STRING for the unknown, compiled by the ordinary evaluator — so list broadcasting, function dispatch, and per-cell error semantics all come free. Exact and deterministic. (2) **Numeric root-finding** on `residual(x) = LHS(x) − RHS(x)` — the fallback when the unknown appears more than once (x² + x…) or behind a non-invertible step (ABS). Scalar-only; bracket scan over a log grid, then bisection; no outside library (the residual is the compiled evaluator). Inversion picks PRINCIPAL branches (√ of a square, ASIN of a sine): the returned value always SATISFIES the equation, but a negative/other-branch solution is the numeric layer's job. **Numeric root selection:** `solveNumeric` bisects EVERY sign-change bracket on the symmetric log grid (±10⁻⁶ … ±10¹²) and returns the root CLOSEST TO ZERO — not the first bracket in ascending order, which would pick the most-negative root (a TVM rate residual also crosses zero out where 1+r < 0, and −290% interest is never the intended answer). The quadratic sniffer exists precisely because symbolic isolation would lose the second root. `#SOLVE!` is the failure code for "no root found".
