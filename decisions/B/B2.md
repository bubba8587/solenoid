## Decision

Desktop runs the full product (native Polars, real file IO); the web build is a look-and-try demo. Features that need files must degrade to a no-filesystem path on web rather than being desktop-only dead ends.

## Why

Relational work runs on native Polars on desktop and an identical JS oracle on web behind the FrameBackend seam (decisions.md polarsEngine). The web demo has to actually demonstrate the product, so file-backed features need a web story.
