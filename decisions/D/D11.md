## Decision

**MUST:** a value of one element family never connects to an input of another. Crossing takes an explicit Cast node.

## Why

[[A6]]: a value's type stays honest end to end. An automatic cross-family connection would coerce silently at the socket, which is exactly the believable wrong answer [[A6]] refuses. A Cast node makes the conversion visible on the canvas.

## Consequences

*Exceptions:* `logical ↔ number` is the one bridge (TRUE/FALSE ↔ 1/0), mirrored at every rank. **Removed by:** nothing. It follows from Excel treating TRUE/FALSE as 1/0. A second exception would be a change to the lattice's design, not a patch.
