## Decision

A composite in any Solve-button (heavy) run mode (Manual/Query, Goal Seek, Monte Carlo, Scenarios, Data Table, By-Row, Simulation) reads blank and stale until the user clicks Solve/Refresh. NO solve on load, paste, create, or a switch into a heavy mode. `isHeavyMode()` is the boundary; plain `single` stays fully live.

## Why

Author 2026-09-13: people expect the value already blank so they see it compute on Solve. A heavy run on load would also stall opening a document.

## Consequences

- **Where:** `composite.ts` `data()` (a never-solved heavy pass returns `{}`, clears `cachedOutputs` / goal-seek readouts, and a mode switch into heavy forgets the prior solve); `composite.test.ts` pins "first pass holds, Solve solves" + the load/mode-switch cases.
- **Reopen if:** the author wants a load-reveal compute back for a specific mode.
