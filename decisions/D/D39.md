## Decision

**MUST:** every set, dedupe, tally or membership test keys through `setKey` (`listOps.ts`). A JS `Set` over raw values is a defect wherever a value might be an array or a tagged object.

## Why

A JS `Set` or `Map` keys objects by reference, so two equal tagged scalars from different sources, such as two complex numbers ([[D45]] maxRankMatrix), never match without a canonical key. The Set node had exactly this bug, and `setKey` was written to fix it for every membership consumer.
