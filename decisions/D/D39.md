## Decision

**MUST:** any set, dedupe, tally or membership test keys through `setKey`. A JS `Set` over
raw values is a defect wherever a value may be an array or a tagged object.

## Why

JS Sets and Maps key objects by reference, so two equal tagged scalars from different sources,
like two complex numbers ([[D44]] tagSpecialScalars), never match without a canonical key. The
Set node had exactly this bug; `setKey` fixed it and lives in `listOps.ts` for every
membership consumer.
