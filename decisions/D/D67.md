## Decision

Predecessors are name-keyed structured records (`{task, type, lag}`) inside the engine. The `3FS+2d` grammar, the vendors' integer link codes (MSPDI, .gan, XER each number them differently) and row numbers or UIDs are parsed at each importer and never become an internal key or a stored string.

## Why

Three vendors number link types three ways, and row numbers break the moment the table is sorted or filtered; a name survives both. The author ruled no in-cell string lists (25-gantt.md § 6.1).

## Consequences

- An importer is a parser to the one record shape; an exporter renders from it.
- **Reopen if:** a plan needs links to tasks with no name (then ids are minted, still not row numbers).
