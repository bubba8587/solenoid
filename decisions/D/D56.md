## Decision

`RENDERER_MIN_NODES = 100`, in KIND-WEIGHTED DOM units (`nodeDomWeight`), not a raw node count: a chart / mermaid / inlined-SVG / frame-grid card is far more DOM than a scalar (~10 charts reach the threshold; a plain scalar graph still needs ~100 nodes). Below the threshold the layer stays fully inert even with render mode 'html' ON. Tunable live via `window.__hcMinNodes`.

## Why

Below the threshold the native DOM pans and zooms fine, and the capture/swap cost (plus any momentary stale-clone flash) isn't worth it. DOM weight, not node count, is what makes a pan expensive.
