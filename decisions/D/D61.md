## Decision

`cloneFor` does NOT set `position` on the clone: each root's own CSS class governs it, exactly like the original (`.solenoid-node` is static, its chrome climbing to the `rel` stand-in div; `.solenoid-note` is `position: relative`, its resize handle anchored to the note card).

## Why

Forcing a single value breaks whichever root doesn't match it: a forced `static` shifted the note's resize handle to the border box (a measured 1.75px shift), a forced `relative` shifted node chrome inside the border; both proven 2026-06-28.

## Consequences

**Where:** `htmlCanvasRenderer.ts` (`cloneFor`).
