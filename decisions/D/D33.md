## Decision

**MUST:** an unwired input (`undefined`) falls back to the node's typed literal. A wired blank (`null`) is a real missing value and propagates; it is never replaced by the literal.

## Why

"Nothing is plugged in" and "the value is unknown" are different facts. Swallowing a wired blank into the literal makes the node answer with a number the user can't see anywhere on the card.
