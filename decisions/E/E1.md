## Decision

**MUST:** where [[D4]] noManualList allows a hand-kept set, a test asserts the observable consequence of membership, not the membership itself: what the function does, not that its name appears in the set.

## Why

Checking a set against a second hand-written list of the same names proves nothing, since both lists can be wrong together. Checking that `T.TEST` returns one number rather than four is a real check.
