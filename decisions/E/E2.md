## Decision

**MUST:** the lattice refuses a Cube into a Frame socket. A verb that should accept a Cube declares a Cube-adoptive input (`cubeAdoptIn` plus `noWidenInputs`, the Add Column and Computed Column pattern) and flattens or refuses inside `data()`. `flatCubeToFrame` treats a flat Cube as rows, and a nested cell is a loud `#SHAPE!` naming the column. The lattice is never widened to spare one node the work.

## Why

The author's words: "cube into frame socket is NOT acceptable. if you have to upgrade something, upgrade the sockets on each node, not vice versa." A Cube can hold nested tables that a Frame can't, so letting one into every Frame socket would make every Frame verb meet shapes it was never built for, while a per-node input keeps the flattening visible and deliberate.
