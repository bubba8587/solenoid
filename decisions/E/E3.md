## Decision

**MUST:** `trueany` adoption (`trueAnyAdopt.ts`) resolves a type without disconnecting
anything, and the adopted type is not written to the save file.

## Why

Adoption is a derived reading of the current wiring, not a fact the user authored: dropping cables would destroy work to satisfy a guess, and persisting the guess would freeze a type the wiring no longer implies.
