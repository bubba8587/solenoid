## Decision

The Type Check op is labeled ISBOOLEAN. `ISBOOLEAN(v)` is registered as a formula function (`excelFunctions.ts`, with the same test as Formula.js's ISLOGICAL), so the all-caps label is a true callable claim and `nameCase.test.ts` needs no allowlist entry for it. `ISLOGICAL` stays callable for Excel parity and is the Inspector's Excel equivalent.

## Why

The author's call: Solenoid's first-class Boolean type is called Boolean on every surface. A [[D23]] capsClaimsFunction sweep had flipped the label to ISLOGICAL.

## Consequences

**Reopen if:** the type itself is renamed.
