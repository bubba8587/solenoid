## Decision

**MUST:** any rule that derives a name (such as [[C51]] formulaNaming's despaced node label) is defined for every input and never maps two different things to one name. Both properties are machine-checked.

## Why

A naming rule without an injectivity check collides silently, and whoever registers second discovers it. Fill's `Interpolate` op and the `INTERPOLATE` node in `stats.ts` both despace to `INTERPOLATE`, so Fill's op declares `fx: "FILLINTERPOLATE"` ([[D3]] overrideInPlace). The full sweep also caught the math-fn `round` leaf claiming `ROUND`, whose 2-argument Excel form refuses the leaf's 1-argument meaning; RoundN at 0 digits covers the same ground, so the duplicate op went.
