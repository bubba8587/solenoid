## Decision

**MUST:** a function taking a whole 1-D list is routed past the element-wise broadcaster.
A function whose arguments are all scalars but whose result is a list is also marked
never-broadcast.

## Why

Without it, the evaluator maps the call element by element and returns N answers to a
question that has one, and a list-returning function builds a 2-D value that slips past the
formula rank cap ([[C15]] matricesInFormulas).
