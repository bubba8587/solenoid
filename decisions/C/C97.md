## Decision

recharts is ONE lazy chunk: every recharts-using renderer lives in `chartRender.tsx`, and nothing the app imports statically may import it. `chartView.tsx`, which every card imports, stays recharts-free and loads the chunk behind `lazy` + `Suspense`.

## Why

recharts is the largest optional dependency and most documents never draw a chart. On the web ([[B2]] webTryDesktopFull) first load is the product's first impression; one static import anywhere in the card tree drags the whole library into the main bundle.

## Consequences

- *Unenforced:* no test walks the import graph for a static recharts import outside `chartRender.tsx`; a bundle-size regression is the only signal. A test would grep `src/` for `from "recharts"` and allow exactly one file.
- **Reopen if:** charts become a core surface most documents use, or recharts is replaced by the canvas figure views.
