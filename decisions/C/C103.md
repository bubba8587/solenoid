## Decision

Content that crosses the app's boundary is guarded at the one seam it crosses:

- A CSV cell that a spreadsheet would evaluate on paste or open is escaped on every export (`csvSafety.ts`), whether it leaves through the popup's Copy or Export or through the Write File sink.
- SVG markup that a user pastes, uploads or fetches is sanitized before it is inlined into the live page or saved (`svgSanitize.ts`).
- A link inside rendered markdown opens externally and never navigates the app's own webview (`externalLinks.ts`).

## Why

Web readers open shared documents ([[B2]] webTryDesktopFull), and a Note carries whatever its author or their vault put in it. Each guard is one rule at one seam rather than a check in every caller, so a new export path or a new markdown surface inherits the guard instead of forgetting it.

## Consequences

- A new way for text, markup or a link to leave or enter the app routes through the existing seam and does not grow its own check.
- **Reopen if:** a surface needs to run untrusted script on purpose. A sandbox is then the seam ([[C66]] scriptNode).
