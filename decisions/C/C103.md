## Decision

Content that crosses the app's boundary is guarded at the one seam it crosses: a CSV cell that a spreadsheet would evaluate on paste or open is escaped on every export (`csvSafety.ts`, the popup's Copy / Export and the Write File sink alike); SVG markup a user pastes, uploads or fetches is sanitized before it is inlined into the live DOM or persisted (`svgSanitize.ts`); a link inside rendered markdown opens externally and never navigates the app's own webview (`externalLinks.ts`).

## Why

Web readers open shared documents ([[B2]] webTryDesktopFull) and a Note carries whatever its author or their vault put in it. Each guard is one rule at one seam rather than a check per caller, so a new export path or a new markdown surface inherits it instead of forgetting it.

## Consequences

- A new way for text, markup or a link to leave or enter the app routes through the existing seam; it does not grow its own check.
- **Reopen if:** a surface needs to run untrusted script on purpose (a sandbox is then the seam: [[C66]] scriptNode).
