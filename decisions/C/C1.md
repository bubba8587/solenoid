## Decision

A bundled demo vault (demoVault.ts + demoVaultData.ts) is served through the fileBridge path-aware fs() dispatch behind the sentinel root solenoid:demo-vault. Vault readers recognise the sentinel and work with no real filesystem; every write throws (read-only). Files are lazily code-split so they never weigh down the main bundle.

## Why

B1 needs the vault integration demoable, and B2 needs it to work on web with no filesystem. Routing by path keeps desktop file ops on the real fs untouched.
