## Decision

There is one append node per rank, taking any number of inputs of any element type: Concat Lists for 1-D, the Stack node (VSTACK and HSTACK) for 2-D, where a ragged edge pads with `#N/A` cells as in Excel, and Append for Frames, where columns match by name and a missing column fills with blanks. All of them use wire-only extensible rows.

## Why

[[B11]] maximalMerge: one append per rank rather than a node per element type. Ragged 2-D stacking pads the way Excel does ([[A5]] excelParity).

## Consequences

- **Deliberately not unified (relapse guard):** Interleave, Pad, Repeat, Add Column, and Build Frame versus Frame from Lists. "Add one row" is Get Row followed by Append; a bare positional list wired into a by-name append is refused as a trap.
- **Reopen if:** a variadic socket that accepts several cables exists; it would collapse the extensible-row pattern.
