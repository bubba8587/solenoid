## Decision

Concat Lists (1-D) · VSTACK/HSTACK (2-D; ragged pads `#N/A` cells like Excel) · Append (frame; union by NAME, missing fills blank). All share wire-only extensible rows.

## Why

maximalMerge: one append per rank rather than a node per element type. Ragged 2-D stacking pads like Excel ([[A5]]).

## Consequences

- **Deliberately NOT unified (relapse guard):** Interleave, Pad, Repeat, Add Column, Build Frame vs Frame from Lists; "add one row" = Get Row → Append (a bare positional list into a by-name append is a refused footgun).
- **Reopen if:** a variadic multi-connection socket primitive; it would collapse the extensible-row pattern.
