## Decision

A document not authored on this machine fetches nothing over the network until the user allows it for that document (`docMetaStore.networkAllowed`, asked once per document); a local document fetches on load as before.

## Why

A shared file could otherwise hit arbitrary URLs, or exfiltrate through them, the moment it opens: the same threat class as the CSV, SVG and link seams ([[C103]] untrustedContentSeams), at the one seam every live fetch already crosses.

## Consequences

- Every fetch path (Connection nodes, data feeds, the SVG Picker's URL source) asks the same gate; a new fetch path routes through it rather than growing its own prompt.
- **Reopen if:** documents carry a provenance the app can trust (a signed origin), which would let the gate default per source.
