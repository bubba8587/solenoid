## Decision

A document that was not authored on this machine fetches nothing over the network until the user allows it for that document (`docMetaStore.networkAllowed`, asked once per document). A document authored locally fetches on load as usual.

## Why

A shared file could otherwise contact arbitrary URLs the moment it opens, or leak data through them. That is the same class of threat the CSV, SVG and link guards handle ([[C103]] untrustedContentSeams), and it is stopped at the one seam every live fetch already crosses.

## Consequences

- Every fetch path (Connection nodes, data feeds, the SVG Picker's URL source) asks the same gate, and a new fetch path routes through it rather than growing its own prompt.
- **Reopen if:** documents carry a provenance the app can trust (a signed origin), which would let the gate choose its default per source.
