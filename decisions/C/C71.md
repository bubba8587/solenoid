## Decision

The Gantt figure is display-only and never writes back. Its chart value is flat JSON on a cable, drawn by a different node from the one that owns the data, and every edit happens in the table, through the Cube Input popup.

## Why

A figure that wrote back would amount to a cable from a display to the literal it displays: a second edit path beside the table. The author's call.

## Consequences

- **Reopen if:** the author asks. It would then come back as the Record node's focused-record model (a display-only pick that a second node follows by name), written as a reopening, and never as a cable from the figure.
