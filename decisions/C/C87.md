## Decision

Groups are React Flow sub-flows. A member is its group's React Flow child (`parentId`, with a position relative to the group box and parents listed before children in the node array), so React Flow tows members with the group and stacks them above it. The model keeps absolute positions, and the conversion between relative and absolute lives only at the boundary: `toFlowPosition`/`fromFlowPosition`, `handlers.moveNode` and `onNodesChange`.

## Why

React Flow's own parenting gives towing and stacking for free, but everything else in the app (saves, Tidy, standoffs, the lasso, docking) reads absolute positions, and each would need its own conversion. One seam costs less than a relative model everywhere. Re-basing a moved group's members at that seam is also what keeps a Tidy consistent when it moves members before their group.

## Consequences

- A membership rebuild re-projects the nodes through the `groupMembershipStore` subscription. During a group drag, the model's member positions follow the group by its per-frame delta, except for selected members, which React Flow moves as part of the selection.
- **Reopen if:** React Flow drops sub-flows, or the model goes relative for some other reason.
