## Decision

5 m and 5 km are different values: relabeling a unit IS overwriting the magnitude, comparatively. An FC downstream of a united value LOCKS (mirrors, never re-authors); only Convert (or a tag-breaking transform) changes a unit. Join-key equality for dimensioned values: dimension symbol + base-SI magnitude (`5 km` == `5000 m`; currency display code is identity, $5 ≠ 5€).

## Why

[[B6]] names first-class units as a headline divergence from Excel, and unit control is a flagship feature: a unit that a dropdown could relabel would make every united number untrustworthy.
