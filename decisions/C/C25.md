## Decision

A unit is part of a value: 5 m and 5 km are different values, so relabeling a unit is overwriting the number. A Format Controller downstream of a value with a unit locks and mirrors it; only Convert, or a calculation that breaks the tag, changes a unit. Join keys with units compare by dimension and base-SI magnitude, so `5 km` equals `5000 m`, and a currency's code is its identity, so $5 ≠ 5€.

## Why

[[A6]] names first-class units as a headline divergence from Excel. A unit that a dropdown could relabel would make every number with a unit untrustworthy.

## Consequences

- **Reopen if:** nothing. This is value-model integrity, in the same class as [[C24]] arraySemantics.
