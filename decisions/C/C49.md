## Decision

List Filter tests a list against its OWN values only (the parallel-list mask is DELETED); table filtering routes through the frame Filter; SUMIFS (SUMIFS/COUNTIFS/AVERAGEIFS/MINIFS/MAXIFS) is the task-shaped conditional aggregate, one frame input + criteria rows per the aligned-columns rule.

## Why

The parallel-list mask made List Filter's behavior opaque from the card; giving each filter node one honest job keeps what it does readable, and conditional aggregation already has its Excel-shaped home.

## Consequences

- **Reopen if:** evidence that non-aggregating parallel-list filtering is common enough to out-vote the mask's opacity. Per-cell 2-D filtering stays out regardless (TOCOL → Filter is the spelling).
