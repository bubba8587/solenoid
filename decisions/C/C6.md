## Decision

A new subsystem, naming law, declaration format, or a sweep touching many files writes or updates its rule node before the code. Ordinary work (a node, a bug fix, a one-line change) just follows the existing rules.

## Why

[[B9]]: a mechanism built before its rule is written leaves the rule to be inferred from the code, which is how rules drift into folklore. This is the working default, not an author ruling; tighten it freely.
