## Decision

Expanding a collapsed group displaces its neighbourhood by a deterministic push over pure boxes (rails, then clear, then residual clear, then cascade), recorded as absolute before/after pairs with the set of contributing groups, and inverted exactly when every contributor is collapsed or deleted. Never ELK in this path. Manual moves win: a node the user dragged since the push stays put, and only real drags (not clicks) invalidate a record.

## Why

Rails and clears are deterministic, preserve deliberate placement, and invert exactly; ELK re-derives positions globally and cannot snap back. Absolute records keep restores order-independent across several expanded groups.

## Consequences

- `setGroupsCollapsed` is the one toggle entry point (chevron, outline panel, hotkey), measuring collapsed-card sizes before the flip because they are the stretch-seam origins.
- A within-group Tidy that grows its box reuses the same engine with no record: a Tidy is a deliberate action, so that displacement is permanent and neighbours never rush back on collapse.
- A programmatic move between two pushes (Tidy, Cleanup, align) voids the old record; the next push starts a fresh one at the current position.
- Standoff corrections fold into the same records so a cluster restores as one block ([[C89]] standoffsSolveLast).
- **Reopen if:** users want a global re-layout on expand rather than minimal disturbance.
