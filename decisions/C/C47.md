## Decision

Every variable is an input AND an output plus a logical `Check`; solving is own AST isolation + bracket/bisection fallback (no CAS dependency). Quadratic residuals return every real root ascending. TVM / Compound Growth / Effective Rate ride the framework (a CONFIG is anything that changes the RELATION).

## Why

maximalMerge: one acausal card covers every relation that can be solved for any of its variables, instead of a solver node per formula. Owning the solver keeps it small and dependency-free.

## Consequences

- **Deliberately NOT converted (relapse guard):** Depreciation, IPMT/PPMT/CUMIPMT/ISPMT (derived quantities, not relations), DOLLARDE/FR, bonds/T-bills, DIST/INV pairs (no closed-form CDFs).
- **Reopen if:** demand for cubic+ roots (Cardano or a vendored CAS).
