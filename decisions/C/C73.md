## Decision

The node Inspector shows STATIC reference for the selected node and its current configuration: the Function Reference derivation plus the node's socket roster described in plain English (`SOCKET_TYPE_LABELS`). It never shows live values and never shows live connections.

## Why

Author call, 2026-08-17. Live values already have their home (the card and its popups) and live connections theirs (the canvas and the Cable inspector); a third live view would be a second copy of each, drifting from the one the user acts on (declareOnce). Until now this ruling lived only in a code comment.

## Consequences

- **Where:** `components/InspectorPanel.tsx`; it READS the same derivation the Reference overlay renders (`buildFunctionReference`).
- **Reopen if:** a workflow needs a live readout the card and Cable inspector cannot give.
