## Decision

JS `<`/`>` on raw strings (UTF-16 code units) for every comparison and data sort. Case- and accent-sensitive; diverges from UTF-8 only on astral-plane characters (deliberately not chased). UI lists keep locale/natural sort.

## Why

Determinism (no host ICU dependence) and Polars byte-order parity: [[B2]]'s two engines must sort identically, and a locale sort would vary by machine.

## Consequences

- **Where:** `stringOrder.ts`.
- **Reopen if:** demand for locale-aware data sorts; needs a per-document locale pin, recorded as a new decision.
