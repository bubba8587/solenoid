## Decision

A provider API key lives only in this device's localStorage (`apiKeyStore.ts`). It is never written into a saved graph, never part of the text form, and never sent anywhere but the provider's own endpoint.

## Why

A document is shared, opened elsewhere, committed to a vault; a key inside it would leak the moment any of that happened. [[B13]] aiInScope puts an AI edit on the same governed path as a human's, and a credential is not document content.

## Consequences

- A document that needs AI on another machine asks that machine for its own key; there is no "key travels with the file" path to add.
- **Reopen if:** a team key store exists (then the seam is a provider, still not the document).
