## Decision

What the author changes in the vault is a work list an agent must process, never a silent edit: a note dropped in `decisions/outbox/`, one of four flat action tags on a node, `ratify`, `retire`, `contest` or `ask`, as a tags property or an inline hash-tag (the author ruled out nested tags), or a `ratified_by` typed into the Properties pane; never a bare diff, since an anonymous edit cannot be told from an agent's own unfinished work and validate already lists changed nodes. `python tools/dte.py outbox` lists them with the exact command each needs; validate prints the count; `outbox --done <ID|slug>` clears one once processed. Each agent session starts by processing the outbox.

## Why

[[B1]] makes Obsidian the author's desk, and the author edits there without a terminal. [[B8]] makes the tree the one home, so a change the author wants made in the vault must land in the tree with provenance (a History line, a ledger line, the owner-kept ratified list) rather than sit as an anonymous diff. The inbox already carries the agent-to-human direction; the outbox is the human-to-agent one. Tags and a folder are the two gestures Obsidian makes cheap, and git already knows what changed, so no watcher or plugin is needed.

## Consequences

- The author's word is the authorization: an edit or tag from the vault is processed under B25, with `authorized_by` naming the author where the node is human-held or above the agent's ring, and never re-asked.
- Nodes carry `aliases` from their `name` so `[[branchModel]]` resolves in the vault; a citation the tool counts still uses the ID. Obsidian's `aliases`, `tags` and `cssclasses` are known fields.
- The parser reads Obsidian's rewrites: `null` as empty, block lists, reordered keys. A ratification made in the working tree no longer fails the human-held check (the node at HEAD was not human-held).
- `decisions/DTE.base` gives the Outbox, Unratified, Contested, Inbox and All views in Obsidian.
- **Reopen if:** a DTE plugin for Obsidian processes the outbox itself, or upstream DTE ships its own human-to-agent channel.
