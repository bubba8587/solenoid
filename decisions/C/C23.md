## Decision

Manual mode (F9) + targeted recompute (a topology change recomputes only the target's downstream closure) are the perf floor. However a recompute is triggered (full pass, targeted cone, manual mode, a live-data refresh) the values on screen are the ones a full clean pass would produce.

## Why

[[A5]]: Excel users expect automatic recalculation, with F9 manual mode for heavy workbooks. The rete-engine pull-with-cache under [[B10]] reactFlowView makes a targeted pass cheap, but every way a cheaper pass can fail leaves a stale value next to fresh ones with nothing marking it. So each rule under this one is an equivalence.
