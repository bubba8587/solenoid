## Decision

`main` is release-only (Vercel + tags); all work lands on `develop`, overriding per-session `claude/*` directives.

## Why

[[B7]]: one author and no release trains, so one development branch beside the production branch is all the structure needed; per-session branches scatter work the author then has to gather.

## Consequences

- The standing order and the release steps live in CLAUDE.md.
- **Reopen if:** multiple contributors / release trains.
