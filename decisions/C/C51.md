## Decision

Legacy aliases never dispatch (`#NAME?` redirect, currentExcelParity on the formula surface). Solenoid-native formula names are BARE, identical to the node's header hover hint (no `SOL.` namespace). Packs register their own formula functions, pack-enable-sensitively.

## Why

B5: a user reads a name off a card and types it; one bare name per function across surfaces (NAME-1) is the on-ramp, and legacy aliases teach spellings Excel itself retired.

## Consequences

- **Reopen if:** a real user corpus leaning on legacy names (soften to documented aliases), or an Excel release colliding with a bare name (case-by-case rename).
