## Decision

Table Input's Source text is the stored truth. Editors never coerce it; only the derived matrix coerces (a blank cell becomes null). A typed blank line survives wherever it is: leading, interior or trailing.

## Why

A popup save that re-serialized through a lossy parse once silently deleted rows ([[B12]] losslessSaves). When the raw text is stored and the matrix derived from it, no edit path can drop what the user typed.
