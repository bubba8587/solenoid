## Decision

Editors never coerce the Source text; only the derived matrix coerces (blank → null). A typed blank line survives everywhere: leading, interior, trailing.

## Why

[[B12]]: a popup save re-serializing through a lossy parse silently DELETED rows. Storing the raw text and deriving the matrix means no edit path can drop what the user typed.

## Consequences

- **Where:** `nodes/matrix.ts` `keepBlankLines`, `TablePopup.tsx`.
