## Decision

A chart's option string is matplotlib's pyplot kwarg vocabulary (`marker`, `markersize`, `fontsize`, `linestyle`…) as a flat `key=value;…` list, deliberately not a private dialect. Unknown keys are ignored so a string degrades rather than fails.

## Why

The people who style charts by text already know one vocabulary, and it is matplotlib's; inventing another would have to be learned and documented for no gain. Ignoring unknown keys is what lets a string written for a newer build load on an older one.

## Consequences

- A new option is added under its matplotlib name where one exists; only a concept matplotlib lacks gets a name of our own, and the spec (`chartOptions.ts` header) lists it.
- **Reopen if:** the options move to structured fields with their own UI, which would make the string a derived view.
