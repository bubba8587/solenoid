## Decision

A chart's option string uses matplotlib's pyplot keyword vocabulary (`marker`, `markersize`, `fontsize`, `linestyle` and so on) as a flat `key=value;…` list, deliberately rather than a private dialect. Unknown keys are ignored, so a string degrades instead of failing.

## Why

People who style charts in text already know one vocabulary, and it is matplotlib's; a new one would have to be learned and documented for no gain. Ignoring unknown keys lets a string written for a newer build load on an older one.

## Consequences

- A new option takes its matplotlib name where one exists. Only a concept matplotlib lacks gets a name of our own, and the spec (the `chartOptions.ts` header) lists it.
- **Reopen if:** the options move to structured fields with their own UI, which would make the string a derived view.
