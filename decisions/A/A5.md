## Decision

Solenoid does not reinvent the spreadsheet function vocabulary. Every Excel function keeps its Excel name and returns Excel's answer. There are exactly three departures: functions Excel itself has deprecated are replaced by their current forms, new functions are added beside the Excel set, and functions that only mean something inside a cell grid (ADDRESS, INDIRECT and their kind) are left out.

## Why

Most people arrive knowing Excel, and a familiar name that returns a different answer is a trap worse than a new name. The owner placed this at the core on 2026-09-17: parity is a founding commitment of the product, not a strategy in service of [[A1]].

## Consequences

- Any remaining difference from Excel is documented where the function is catalogued (parity false, with a note), never silent.
- Which functions count as deprecated, and how the current form replaces them on every surface, is [[C14]] currentExcelParity's.
- The rule families under this node (shared implementation, naming, arguments, comparisons, calc modes) refine how parity is kept, never whether.
