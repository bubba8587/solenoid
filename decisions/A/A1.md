## Decision

Solenoid is a visual computation graph: calculations are primarily built by wiring nodes (cards) on a canvas as the primary interface, rather than typing formulas into cells.

It's a tool for both small arithmetic scratchpad work and for larger data operations. We want to build a tool that sits nicely in the nexus of spreadsheet software + knowledge bases + documents + code + more powerful database tools. 

## Why

This is the founding product identity. Every other decision exists to make this a great tool across its entire scope.
