## Decision

The bare names `pi`, `tau`, `e` and `phi`, in any letter case, always mean the constant, inside a LAMBDA body as everywhere else. A LAMBDA parameter named after one is refused rather than ignored: the formula `LAMBDA(e, e+1)` answers `#VALUE!` and the LAMBDA node answers `#NAME?`, each saying the name is a constant.

## Why

[[C50]] lambdaBindsByName matches a LAMBDA's parameters by name, so a name has to mean one thing wherever it sits: `e` inside a LAMBDA is Euler's number, the same as in any formula. The author's call. Refusing the parameter keeps [[B17]] typedValueModel: a parameter the body could never read would otherwise be dropped silently.
