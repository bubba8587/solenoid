## Decision

A node's name never reads as a core Excel function that does something else: the node that keeps columns is Keep Columns, never a bare Columns, which reads as COLUMNS().

## Why

An Excel user reads a node's name as a promise about what it does, so borrowing a function's name for another job is a trap.

## Consequences

- How it's checked: [[add-menu#Naming a placed node]].
- **Reopen if:** never.
