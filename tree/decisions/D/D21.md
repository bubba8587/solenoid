## Decision

**MUST:** a node's name never reads as a core Excel function that does something else. A bare "Columns" reads as COLUMNS(), which counts columns, so the node that keeps or drops columns is named for what it does: "Keep Columns" or "Drop Columns".

## Why

A node's name is how it is named everywhere, and an Excel user reads that name as a promise about what it does. A node that borrows a function's name for an unrelated job is a trap.
