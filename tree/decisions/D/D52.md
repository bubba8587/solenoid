## Decision

A composite in a heavy run mode, meaning any mode with a Solve button (Manual or Query, Goal Seek, Monte Carlo, Scenarios, Data Table, By-Row, Simulation), reads blank and stale until the user clicks Solve or Refresh. It never solves on load, paste, create, or a switch into a heavy mode. The plain Single mode stays fully live.

## Why

The author's call: people expect a heavy composite to sit blank so they can watch it compute when they press Solve. Solving on load would also stall opening a document.

## Consequences

- Heavy means holding is the point, not only cost. Manual refresh runs one pass and is heavy anyway, because holding until Refresh is its whole job. Monte Carlo is heavy only when some input actually varies.
- By-Row is the one heavy mode whose pass count comes from the data rather than a typed number, and every pass recomputes the whole inside of the composite, so a huge wired table would freeze the Solve. It caps at 500 rows, and because the cut-short series still looks plausible, it warns loudly (the Alerts HUD and a toast) instead of dropping rows silently.
- **Reopen if:** the author wants a mode to compute on load again. How it's built: the composite-nodes spec.
