## Decision

In Obsidian, the plugin's Save writes each cell as it was typed. Picking a column type only changes how the cells show, never what the note holds, and a cell the type can't read shows as unreadable instead of being refused.

## Why

What you typed is the truth, so picking a type should never cost data. If Save wrote converted values, switching a date column to Number would wipe the dates.

## Consequences

- *Exception:* a Complex property has no editor of its own, so it refuses text it can't read and writes nothing. **Removed by:** a Complex control in the app, which the plugin would then bundle.
- How it's built: [[obsidian-plugin#Requirements]].
- **Reopen if:** a note can store an error value for a cell, or the app's own editors stop keeping what was typed.
