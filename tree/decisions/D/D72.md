## Decision

In Obsidian, Save writes each cell as it was typed. Picking a column type only changes how cells show, never what the note holds.

## Why

What you typed is the truth, so picking a type should never cost data.

## Consequences

- *Exception:* a Complex property has no editor of its own, so it refuses text it can't read and writes nothing. **Removed by:** a Complex control in the app, which the plugin would then bundle.
- How it's built: [[obsidian-plugin#Requirements]].
- **Reopen if:** a note can store an error value for a cell.
