## Decision

**MUST:** when an empty formula argument, or an empty setting field on a card, counts as some value other than empty text, that value shows in place as muted placeholder text. It shows in the formula editor, wherever a formula is drawn read-only (such as a card's formula line), and in the card's own field. An empty slot that stands for a default shows a short word for that default. An empty data field stays plainly empty, because its blank really is blank.

## Why

A value nobody typed still changes the answer, so it has to be visible where it acts; nothing changes behind the user's back ([[B17]] typedValueModel).

## Consequences

- How it's built: [[input-roles#Placeholders]].
- **Reopen if:** a placeholder can't be drawn without moving the text the user typed.
