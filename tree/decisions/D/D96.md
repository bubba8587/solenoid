## Decision

**MUST:** an empty formula argument slot, or an empty setting field on a card, whose reading isn't "" shows that reading in place as muted placeholder text: in the formula editor, wherever a formula is drawn read-only (a card's formula line), and in the card's typed field. A slot read as left out shows a short word for the default it stands for. A data field stays plainly empty, because its blank really is blank.

## Why

A value nobody typed still changes the answer, so it has to be visible where it acts; nothing changes behind the user's back ([[B17]] typedValueModel).

## Consequences

- How it's built: [[input-roles#Placeholders]].
- **Reopen if:** a placeholder can't be drawn without moving the text the user typed.
