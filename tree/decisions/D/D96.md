## Decision

**MUST:** every card field and every formula argument slot declares what it is when empty, one of four kinds, and shows it in place. A **Fallback** is a value the card computes with, shown muted. A **Behavior** is something the card does, shown muted as a word in brackets (`[all]`). An **Example** is a hint shown muted in italics; the card computes nothing from it, so a blank there may blank the card. **Required** shows nothing, and the card answers an error naming the field. Nothing a card computes from is hidden: a value it uses when a field is empty is that field's Fallback.

## Why

A value nobody typed still changes the answer, so it has to be visible where it acts; nothing changes behind the user's back ([[B17]] typedValueModel). A cleared card should still answer something sensible instead of an error from nowhere, and a person should tell at a glance whether a muted placeholder is used or only suggested.

## Consequences

- Fallbacks are chosen with care, to keep a wiped card from answering a nonsense error: a field that holds the values the card works on usually falls back to Excel's empty value (0, FALSE or empty text), a setting to whatever it needs. An Example goes where a blank answer is fine.
- Italics belong to Examples alone; a Fallback and a Behavior are upright.
- A field's default, the value a fresh card ships in it, usually matches its Fallback but need not.
- The formula surface reads an empty slot as Excel's blank for its parameter ([[C80]] blankArgIsExcelBlank).
- *Unenforced:* the fields on the worklist (`tests/fixtures/empty-field-worklist.json`) declare nothing yet, and some bodies still compute from a value their field doesn't show; the test only lets the list shrink. **Removed by:** the list reaching empty.
- How it's built: [[inline-literal-maps#What an empty field is]], [[input-roles#Placeholders]].
- **Reopen if:** a placeholder can't be drawn without moving the text the user typed, or the kinds can't be told apart at a glance.
