## Decision

Local File reads a whole folder by its name field: a name with `*` (or `?`, or `**/` for subfolders) takes every CSV and Parquet file it matches and stacks them into one table, with a first column, File, naming the file each row came from. Columns meet by name, as Append's do, a file lacking a column leaving blanks there. A file that doesn't read is named on the card and the rest still load. It is not a card of its own.

## Why

Reading one file and reading a folder of them are one job, so they are one card ([[B11]]): the author asked for Excel Power Query's From Folder, and a second card would differ only in how many files it opens. The agent chose the pattern-in-the-name form and the union of columns; the author asked for the feature, not these details.

## Consequences

- How it's built: [[live-connections]] § A folder as one table.
- **Reopen if:** files in one folder routinely differ in shape enough that the union is mostly blanks, or a per-file transform before stacking is wanted (Power Query's sample-file step).
