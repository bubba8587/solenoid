## Decision

**MUST:** a node that changes a socket's `dataType` in place fires no connection event, so it must call `reconcileFcTypes` or `retypeOutputCables`. Examples: Cast's target, a LAMBDA table's result type, Get Column's read-as, Note frontmatter, List and Table Input element types, Add and Split Column, CableSwitch, Import from Obsidian. The completeness scan owns the full list.

## Why

Without it, downstream Format Controllers keep formatting by the old type.
