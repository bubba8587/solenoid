## Decision

**MUST:** a placed node's default title is the catalog name of what the user clicked. For an op family (a family declared in `NODE_OPS`) that is the name of the current op, kept live: a placed ABS reads "ABS", never "Math", and switching XNPV's toggle to Periodic retitles it "NPV". No class hardcodes a family title (every op family sets `this.label = init?.label ?? ""`), and no component syncs a label when the op changes. The one derivation is `nodeDisplayName` (`catalogUtils.ts`): the user's own label if they typed one, else `nodeName` (the op-aware catalog index, which skips the generated "Host: Op" search rows), else the class name. Every surface that names a node (card header, Navigator, Inspector, cable inspector, history digest, popup titles) reads it.

A leaf name is therefore a card title: no glyph prefixes ("+ Add"), no hints ("ROUND to N digits"), and an "X / Y" row that creates only X is split into two leaves (`leafOps`).

**Exception, the card's hover type-hint (the author's call):** the small hint on the right of the card (`.solenoid-node__type-hint`, shown on hover) gives the op-agnostic family name from `nodeTypeName` ("Series", "Math FX"), not the op that the header and dropdown already show. That name is the class name with its suffix removed and spaces added, so a family that reads wrong is fixed by renaming the class (for example `MathFnNode` to `MathFXNode`), never with an override map.

**Exception, the Conduit (the author's call):** a Conduit's default title is `Conduit N`, its sequence number, not the bare catalog name, so every Conduit reads distinctly in the Navigator. A blank or bare "Conduit" label takes the numbered default, on placement and on load. **Removed by:** the Navigator telling same-named cards apart on its own.

## Why

The name on the canvas is the only thing a reader has. A card titled by its family ("Aggregate", "Arithmetic") or by a sibling op ("IRR" on a dated XIRR) misreports what it computes, and the Add menu then names things the canvas never shows. The hover hint states the kind of node once without duplicating the op dropdown.
