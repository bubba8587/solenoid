## Decision

Charts draw with TanStack Charts: every figure that plots data is a TanStack chart definition rendered through its React adapter on the canvas and through its static SVG renderer for export. No second charting library sits beside it.

## Why

One library that draws the same definition on screen and to a file lets a chart export from anywhere, and it is smaller and faster than the one it replaced, so charts stay cheap as their number grows.

## Consequences

- How it's built: [[chart-figures#Render dispatch]] and [[engineering#Heavy libraries load lazily]].
- The figures that are not plots (KPI, Record, Gantt, Mermaid diagrams, the 3-D Surface) keep their own renderers.
- **Reopen if:** TanStack Charts stops being maintained, or a figure we need cannot be drawn with it.
