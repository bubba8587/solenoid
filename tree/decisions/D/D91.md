## Decision

A Scatter, XY Line or Bubble chart can name in its options which columns are x, y, marker size, marker color, point text and series, rather than having an input for each. Unnamed, the first column is x and the later number columns are y series. A named column the data lacks is an error on the chart, never silently ignored.

## Why

Not every table reads as "first column is x, the rest are series": a parametric t, x, y table should plot y against x, not both against t, and a size or label column would become one more series. Naming each column's role is how pandas plots a table, so it fits the option names people already know ([[C96]] chartOptionsAreMatplotlib). A misspelt column ignored would draw a plausible wrong chart.

## Consequences

- How it's built, and the option keys: [[chart-figures#XY plots]].
- **Reopen if:** the options move to separate fields per chart type, where a column picker could replace typed names.
