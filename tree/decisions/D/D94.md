## Decision

Every place that shows a number nobody formatted shows it the same way, the Format Controller's General style: a whole number as it is, anything else to the Decimal places setting (2, 3, 4 or 6; 4 by default) with trailing zeros dropped, and very large or very small numbers in scientific notation.

## Why

The same number shown four ways depending on where you look (0.2203 in a value box, 0.22 on a table card) makes you doubt which is the value. General is already the default a user can pick, so it is the default display.

## Consequences

- A number turned into text as data (Cast to text), the Constant cards, which exist to show a constant's precision, and chart axis ticks keep their own rule.
- How it's built: [[format-model]] (Styles).
- **Reopen if:** one surface needs a different default than the rest; it then takes a Format Controller, never its own constant.
