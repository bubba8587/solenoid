## Decision

Every surface that shows a number without a format the user picked shows it the one way the Format Controller's General (auto) style does: an integer as it is, anything else to 6 significant digits with trailing zeros dropped, and scientific for extreme magnitudes. Value boxes, Frame and Table cards, the Table and Cube popups, complex numbers and unit suffixes all use it.

## Why

[[C94]] formatFamilyGates gives decimal places one rule, and the same number read four ways by surface (0.220339 in a Format Controller, 0.2203 in a value box, 0.22 on a Frame card, 0.22033898305084745 in a Cube cell) makes a user doubt which is the value. General is already the named default a user can pick, so the default display is that choice made for them. Six significant digits keep a small value from reading as 0.00, and dropping trailing zeros keeps 1.5 from reading as 1.5000.

## Consequences

- The formatter is `formatScalar` (`components/format.ts`); the Format Controller's `auto` style is the same function.
- A number turned into text as data (Cast to text, a complex number in a text formula) is not a display and keeps its own rule.
- Displays that exist to show a constant's precision (the Constant and Physics Constant cards) and chart axis ticks keep theirs.
- **Reopen if:** a surface is too narrow for 6 significant digits; that surface then takes a Format Controller, never its own default.
