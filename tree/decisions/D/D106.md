## Decision

Solenoid's formula function library (SUM, XLOOKUP and the rest) will be published as its own open-source Rust package once the app is more stable, with today's frozen answers as its tests. Until then it stays inside Solenoid.

## Why

Solenoid now owns every function, so others could use them. A public package has to keep its interface stable, and the engine shouldn't promise that while it's pre-alpha.

## Consequences

- Publishing waits on layering the core, so the function library can stand alone (`docs/backlog.md` § Rust core).
- **Reopen if:** another project needs the functions before the app settles.
