## Decision

The graph runs on the Rust core too, not only formulas, functions and Frame verbs. That covers which nodes and cables exist, the calculation pass that runs them, and what reruns when something changes. It's built on Ruggine, Solenoid's Rust port of rete, kept as its own library. Only the UI stays TypeScript: React components, the canvas and gestures. Each piece moves the way D99 rustIsSpec moves the rest: the TypeScript goes once the core covers it.

## Why

One implementation of everything that computes keeps answers the same wherever they run and makes them fast everywhere; rete was an outside library, so it was ported as one rather than inside Solenoid.

## Contest

### Contest 2026-10-24 by Claude Opus 5.5: keep wins

keep: C130 rustCore puts computation on one Rust core, and the graph's pass, its walks and the card bodies it calls are computation, so the graph moving there follows from the parent. opposite (the graph stays in TypeScript) leaves a second implementation of what computes, which C130 rules out, and keeps a JS hop between every card on the core. deletion: C130 alone says formulas compute on the core but not that the graph does, or that rete is ported as its own library; D102 carries that. No variant beat keep.
