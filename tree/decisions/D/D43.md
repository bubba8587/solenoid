## Decision

A list carries a unit on each item, a Frame one per column, and a matrix one for the whole grid; never one per matrix cell, or one for a whole list.

## Why

A unit belongs to the value, so it sits exactly where values are sure to agree: finer wastes, coarser lies.

## Consequences

- How it's built: [[unit-flow#One idea, a carrier per rank]].
- **Reopen if:** per-column units on unnamed matrices are wanted. That is what a Frame is for.
