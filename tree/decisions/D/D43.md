## Decision

**MUST:** a list carries a unit on each item, a Frame one unit per column, and a matrix one unit for the whole grid, never a unit per matrix cell or one unit for a whole list.

## Why

[[C25]] firstClassUnits makes the unit part of the value, so it attaches where values are guaranteed to match: a Frame column holds one kind of thing, a matrix is one quantity, and a list's items don't have to agree. A finer attachment wastes; a coarser one lies.

## Consequences

- A special matrix type that carries its own unit was rejected: it would have meant reworking every conversion between shapes for a small payoff. How it's built: the unit-flow spec (One idea, a carrier per rank).
- **Reopen if:** per-column units on unnamed matrices are wanted. That is what a Frame is for.
