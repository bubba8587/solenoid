## Decision

**MUST:** a node can do everything the formula it shares a name with can. Every argument, mode and result shape the formula reaches has a socket, op or control on the node, rather than the node offering less and leaving the rest to the formula bar.

## Why

A function is the same as a node or a formula, so the node is a complete answer to what that function does. The author's standing order (2026-08-21).

## Consequences

- *Exception:* an argument whose meaning lives only in a cell grid, or one the formula accepts and ignores (IRR's guess), has no socket; the reason is recorded against that function. **Removed by:** the formula giving that argument a meaning.
- How it's built: [[node-classes]].
- **Reopen if:** a function's reach can't be shown on a node without making it unreadable.
