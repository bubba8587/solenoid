## Decision

**MUST:** a node can do everything the formula it shares a name with can: every argument, mode and result shape has a socket, op or control on the node.

## Why

A function is the same as a node or a formula, so the node should be a complete answer to it. The author's standing order (2026-08-21).

## Consequences

- *Exception:* an argument whose meaning lives only in a cell grid, or one the formula accepts and ignores (IRR's guess), has no socket. **Removed by:** the formula giving that argument a meaning.
- How it's built: [[node-classes]].
- **Reopen if:** a function's reach can't be shown on a node without making it unreadable.
