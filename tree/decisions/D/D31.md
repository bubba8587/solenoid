## Decision

**MUST:** the calc mode (manual, automatic or sketch) and the dirty flag form a real state machine. In manual mode an edit marks the graph dirty instead of computing. Switching to automatic or sketch clears the pending flag, and the caller owes the catch-up recompute; the store itself never runs a pass. If localStorage is unavailable, the mode falls back to in-memory state, never to a graph that quietly stops recomputing.

## Why

A graph that has stopped recomputing looks exactly like one that doesn't need to, so the mode's transitions need direct tests. They once shipped with none.
