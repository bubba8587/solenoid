## Decision

Solenoid Properties gives other Obsidian plugins a small, versioned way to show and edit a Frame property with its own chip and editor, and to read and record that Frame's column types. It only grows within a version; a breaking change is a new version.

## Why

A Frame should look and behave the same wherever it shows up, including in another plugin's view. A stated API lets that plugin use the real chip without reaching into private code that any update could break.

## Consequences

- How it's built: [[obsidian-plugin#The API for other plugins]].
- **Reopen if:** no other plugin uses it.

## Contest

### Contest 2026-09-29 by Claude Opus 5.5: keep wins

Opposite (no stated API) leaves the Decision Matrix view reaching into private methods, which C107 obsidianPlugin's same-chip-everywhere promise cannot survive a refactor under; deletion leaves C107 silent on how a second plugin gets the chip and the column types. Keep wins.
