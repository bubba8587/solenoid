## Decision

**MUST:** a unit is a base-SI `UnitCell` set at the value's origin: a Format Controller (`applyFcUnit`), Convert, or a Frame column's declared unit (a header spec or the popup's unit picker, stored as a `ColumnUnit`, which a computed column carries like any data column). It rides through passthroughs and selectors and breaks at any transform.

Downstream, an inherited unit is never set again. An FC fed a value that has a unit mirrors it and locks (`unitLocked = lockedByConvert || forwarding`). Nothing walks the graph to propagate units. The one sanctioned graph read is Convert telling its FC which unit to show (`refreshAnnotation`), which sets the FC's own dropdown and never re-tags a value. The Number node is a plain literal source.

## Why

[[C25]] firstClassUnits: a unit is part of the value. Setting it only at the origin means every unit change is a visible Convert that rescales the number, never a dropdown relabel that silently changes what the number means.
