## Decision

**MUST:** a unit is attached only where a value is made (a Format Controller, Convert, or a Frame column's declared unit), and travels with the value from there. It drops at any node that computes something new, and it is never set again downstream: a Format Controller fed a value that already has a unit shows that unit and locks its dropdown, instead of relabeling it.

Units are never pushed through the graph from outside the value. The one exception: Convert tells the Format Controller feeding it which unit to show, which sets that controller's dropdown and never changes a value's unit.

## Why

[[C25]] firstClassUnits: a unit is part of the value. Setting it only where the value is made means every unit change is a visible Convert that rescales the number, never a dropdown relabel that silently changes what the number means. How it's built: the format-model and unit-flow specs.
