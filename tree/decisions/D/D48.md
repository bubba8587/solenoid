## Decision

A number a calculation can't represent never leaves the node as a bare not-a-number or infinity: that node turns it into a named error (#DOMAIN! or #OVERFLOW!). An infinity that came in as one passes on.

## Why

Errors stay apart from numbers so a wrong answer never looks right, and only the node that produced it knows why.
