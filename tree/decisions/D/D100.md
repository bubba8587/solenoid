## Decision

A computed column with no authored unit takes the unit its formula works out from its input columns' units and its wired values' units, as Expression does: `@price * @qty` over a $ column is $, `@dist / @time` over km and h is km/h, `@hi - @lo` over °C readings is K, `(@lo + @hi) / 2` is °C. An authored unit still wins, and a clash with it is `#UNIT!`.

## Why

A column holds one unit, so the formula's unit is one dimension pass per column, not per row. Before this, a computed column read its cells as bare numbers and carried only a typed unit, so a unit silently dropped at the one place a table does arithmetic, and a wired value's unit was stripped before the formula read it. Unit control is a flagship ([[A6]]), and this is the rule Expression already follows.

## Reopen if

A column's cells stop sharing one unit, or the dimension pass costs more than a column's evaluation.
