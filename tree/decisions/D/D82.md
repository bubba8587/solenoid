## Decision

The SPARKLINE formula answers a small picture of a range as text, so it fits in a table cell: a line, columns or a win/loss strip, the Sparkline node's three types. A long range is averaged down to a fixed number of points. Wherever the picture shows, it is painted in the active palette's colors, while its text stays the same on every palette.

## Why

A table cell holds a number, text, true/false or a blank, never a chart, so a chart per row has to travel as text. A sparkline column runs once per row over a whole table, so each picture's size must not grow with the data ([[C21]] matchNodeLimits).

## Consequences

- A save, a copy or an export gives the same text on every palette; only the display repaints.
- How it's built: [[formula-language]] (SPARKLINE).

## Contest

### Contest 2026-09-29 by Claude Opus 5.5: keep wins

Fixed colors vs palette-following. Baking the active palette into the value would make saves and exports change with the palette and would go stale until a recompute; fixed colors clash on non-Default palettes. Verdict: keep the Default hexes in the value and repaint at display, on the author's word (2026-09-29).
