## Decision

While a Frame header is being named, Solenoid Properties suggests the column names already typed in the vault's Frame and Cube properties, and picking one also sets that column's type to the one it has there. A setting turns it off, and the same list is offered to other plugins through the API.

## Why

A Frame column is often a property split across notes (every option note's scores Frame has a cost column), and a typo makes a second column that silently scores nothing. Obsidian suggests property names for the same reason. Only typed columns are offered because a recorded type is the only vault-wide record of a Frame's columns the plugin keeps, and it carries the type the pick should take. It is a setting because suggestions are a help some vaults do not want.

## Consequences

The mechanics are [[obsidian-plugin]] § Column name suggestions, and the header's list is [[table-popup]] § Editing a cell.
