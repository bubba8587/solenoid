## Decision

While you name a Frame column, Solenoid Properties suggests the column names already typed elsewhere in the vault, and picking one also gives the column that type. A setting turns it off.

## Why

A Frame column is often the same field spread across many notes, and a typo quietly makes a second column that counts for nothing. Suggesting the names already in use prevents that, as Obsidian does for property names; some vaults won't want it, so it can be turned off.

## Consequences

- How it's built: [[obsidian-plugin#Column name suggestions]], and the header's list in [[table-popup#Editing a cell]].
- **Reopen if:** people want suggestions from columns nobody has typed.
