## Decision

In a table's grid, a text cell holding a picture address (`data:image/`) shows as the picture, sized to the row. The cell's value is still the text, so copy and export give the text. A web (http) address stays text in a grid.

## Why

A long encoded picture address is unreadable as text. A picture address carries the picture inside it and fetches nothing, while a web address would reach out to the network from every row ([[C103]] untrustedContentSeams).

## Consequences

- The Form view and the Record figure keep a wider reading that also shows a picture from a web address.
- How it's built: [[table-popup#Formatted and Source]].
