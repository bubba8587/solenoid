## Decision

In a table's grid (a Frame or Cube card, the Table popup, the Cube popup), a text cell whose text is a `data:image/` address shows as that picture, sized to the row. The cell's value is still the text, so copy and export give the text. An http address stays text in a grid.

## Why

[[D82]] sparklineCell puts pictures into cells as text, and a long encoded address is unreadable as text. A data address carries the picture inside it and fetches nothing, so showing it crosses no seam [[C103]] untrustedContentSeams guards; an http address would reach out to the network from every row, so a grid leaves it as text.

## Consequences

- The Form view and the Record figure keep their wider reading, which also shows an http image address.
- How it's built: the table-popup spec.
