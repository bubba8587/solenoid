## Decision

**MUST:** an input with nothing plugged in uses the value typed on the node. An input that is plugged in and receives a blank keeps the blank: it is a real missing value, it passes on downstream, and the typed value never replaces it.

## Why

"Nothing is plugged in" and "the value is unknown" are different facts. Replacing a wired blank with the typed value makes the node answer with a number the user can't see anywhere on the node. How a node reads its inputs is in the value-semantics spec.
