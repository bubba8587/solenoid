## Decision

The Comparison card's ops are functions taking values first: IS, ISNOT, ABOVE, BELOW, ATLEAST and ATMOST(values, x), each a TRUE/FALSE per value; BETWEEN takes values too, BETWEEN(values, low, high). Each card and its function are one implementation, so they answer alike on dates, units and blanks. The raw operators (=, <>, <, >, <=, >=) stay as Excel has them. Sets, Between, Comparison, Is In and Tally make up the Sets pack, which is on by default.

## Why

The author's call (2026-11-04): named tests read more cleanly than raw comparison operators, and a card that is its formula can't drift from it; the tests and the set operations are one family, so they live together as a pack a document can rely on being there.
