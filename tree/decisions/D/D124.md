## Decision

The Comparison card's ops are functions taking values first: IS, ISNOT, ABOVE, BELOW, ATLEAST and ATMOST(values, x), each a TRUE/FALSE per value; BETWEEN takes values too, BETWEEN(values, low, high). The functions and the raw operators (=, <>, <, >, <=, >=) are one comparison and answer alike, blanks included, as Excel's operators do (a blank reads as 0 or empty text). The cards differ only on a blank: the Comparison and Between cards answer blank for a blank input. Sets, Between, Comparison, Is In and Tally make up the Sets pack, which is on by default.

## Why

The author's call (2026-11-04): named tests read more cleanly than raw comparison operators, and the formula surface must behave one way, so a function never differs from its operator; a card can treat a blank differently because a card has defaults and placeholders to show; the tests and the set operations are one family, so they live together as a pack a document can rely on being there.
