## Decision

The Comparison card's ops are functions taking values first: IS, ISNOT, ABOVE, BELOW, ATLEAST and ATMOST(values, x), each a TRUE/FALSE per value; BETWEEN takes values too, BETWEEN(values, low, high). The functions, the raw operators (=, <>, <, >, <=, >=) and the Comparison and Between cards are one comparison and answer alike, blanks included: a blank on either side answers blank, as every operator does ([[C24]] arraySemantics). A card differs only in what it reads: an unwired input takes its typed value or placeholder. Sets, Between, Comparison, Is In and Tally make up the Sets pack, which is on by default.

## Why

The author's call (2026-11-04): named tests read more cleanly than raw comparison operators, and the formula surface must behave one way, so a function never differs from its operator; a card's defaults and placeholders are where it may read differently; the tests and the set operations are one family, so they live together as a pack a document can rely on being there.
