## Decision

**MUST:** for each chart type, the Chart Builder offers exactly the options that chart type draws, no more and no fewer. An option the chart reads is offered for it, and an option offered for it visibly changes the figure everywhere it is drawn: on the node, in a Display, in the popup and in a Report.

## Why

[[C96]] chartOptionsAreMatplotlib makes a chart's options a typed list, but most people set them in the Chart Builder, so an option missing from it is invisible and an option that does nothing looks broken. Nothing else ties what the Chart Builder offers to what each chart actually draws, so the rule and its test do.

## Consequences

- A chart that learns an option offers it in the Chart Builder in the same change; one that drops an option stops offering it.
- *Unenforced:* whether an option visibly changes a figure needs the figure drawn on screen, and the test suite doesn't draw. A test pins the title option; the rest is checked by eye whenever the Chart Builder's options or a chart change.
- **Reopen if:** the options move to separate fields per chart type, so the Chart Builder's list could be derived. How it's built: the chart-figures spec.
