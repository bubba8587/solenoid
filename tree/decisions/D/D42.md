## Decision

**MUST:** raw `UnitCell`s never reach a node that doesn't run the dimension algebra. `coerceInputs` unwraps them to display magnitude in one place. `unitAware = true` keeps tags on every input, and a `passthrough()` node keeps them only on its spec-named inputs, so side inputs unwrap. **A new algebra node MUST set `unitAware = true`.**

## Why

Without this, a tagged cell reaches a node that compares it as a plain number, and `5 km > 3` answers wrong.

## Alternatives considered

### Contest 2026-09-16 by Claude Fable 5.1: keep wins

Judged by [[C25]] alone. keep: the strip is central (coerceInputs) and a node opts in per input, so a unit-blind node never sees a tag and an algebra node sees every tag; cost = one flag per algebra node, pinned by a source scan. opposite (every node receives UnitCells): every data() in nodes/ and packs/ must unwrap by hand, the 5 km > 3 regression returns at each site. deletion: [[C25]] says only the algebra changes a unit but not where the boundary sits; the strip point would be re-derived per node. Acted under it: TriangleSolverNode sets unitAware to read angle cells in degrees.
