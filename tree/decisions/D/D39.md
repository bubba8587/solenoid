## Decision

**MUST:** every set, dedupe, tally or membership test compares values by what they are, never by where they came from. Two equal values from different nodes count as the same value.

## Why

Some values, such as complex numbers ([[D45]] maxRankMatrix), are compared by identity unless care is taken, so two equal ones from different sources would never match. The Set node had exactly this bug. How values are compared is in the formula-language spec (Sets).
