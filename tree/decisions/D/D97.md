## Decision

The Rust core is a line-for-line port of the TypeScript, which stays the specification: where the two answer differently, the Rust is wrong, even when its answer looks more reasonable. **MUST:** every verb, function body and formula path the core carries is checked against the TypeScript by a differential test on random inputs, to the bit.

## Why

Two implementations that each decide answers drift apart, and the TypeScript is the one people read and change; a check that compares them on every run is what keeps them one product.

## Consequences

- The mechanics, the JavaScript semantics the port reproduces and the rebase routine: [[rust-core]].
- A bug found in the TypeScript while porting is fixed in the TypeScript, and the port follows.
