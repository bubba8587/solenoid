## Decision

**MUST:** a value's display format (decimals, percent, date style and the like) flows downstream, its unit does not flow this way, and the format survives only a step that keeps the value's meaning.

- **Carries:** add and subtract (5% + 3% is a percent, a date + days is a date); mean, min, max, standard deviation, moving windows and EWMA; ABS, ROUND, MROUND and clamp; EDATE and WORKDAY keep a date.
- **Doesn't carry:** multiply, divide, power and MOD; count, variance and product; z-scores and correlation; every finance result (NPV, a rate, CAGR, Sharpe); a free-form Expression; and date − date or NETWORKDAYS, which give a span, not a date. A change of kind, like number to text, carries nothing.
- **Pass-through nodes** (Sort, Reverse, Slice, Filter, INDEX, TRANSPOSE) compute nothing new, so they forward the format unchanged.
- **The unit stays on the value** ([[D40]] unitOnValue). So multiplying $10 keeps the $ and drops the 2-decimal format.
- **Overrides.** A nearer Format Controller overrides what it inherits. Its style dropdown also has a "—" pick that keeps the incoming format and sets only the unit, so a Format Controller added just for a unit doesn't reset the style to Auto.
- **Convert drops the format.** It sets a new unit and rescales the number, so precision chosen for the old unit no longer fits.
- **Looking back stops at a calculation.** A value takes the format of a Format Controller placed after it only when nothing but pass-through nodes sit between them, because a format chosen after a calculation says nothing about the value before it.
- **Frames.** A Frame column's format travels with the column, like its unit, and the nearer node's pick wins.

## Why

The author, 2026-09-04: "Generally, we want formatting to carry down the stream if possible, but it's always possible to override. Units are LOCKED in contrast." On 2026-09-13 the author settled what "if possible" means: a step that keeps the value's meaning. A percent's NPV is not a percent, and an integer 7 ÷ 2 is not 4, so a calculation carries the format only where its op keeps the meaning.

Carrying the first formatted input through any calculation gave wrong displays: NPV of a 5% rate showed `123,456.00%`, integer `7 ÷ 2` showed `4`, and `date − date` showed a date. How it's built: the unit-flow spec (format carry) and the format-model spec.
