## Decision

A node that draws random numbers keeps its draw, and draws again only when the user recalculates (F9 or its equivalents).

## Why

F9 is how you ask for a new draw, so an unrelated edit shouldn't change the numbers, and a Monte Carlo built on them stays reproducible.

## Consequences

- *Exception:* a random function inside a formula draws again each time that formula recalculates. **Removed by:** formulas holding their draws until F9 the way nodes do.
- How it's built: [[compute-pass#Volatile nodes and the recalc generation]].
