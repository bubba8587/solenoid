## Decision

**MUST:** Contains, Starts with and Ends with work only on text. On a number, date or true/false column or list they give an error that names the fix (turn the column into text first), in every filter, rather than comparing against the value turned into text.

## Why

A wrong input should be an error you see, never a quiet answer ([[C24]] arraySemantics). A number turned into text depends on how the computer happens to print it, and a format change would look like a data change.
