## Decision

**MUST:** Contains, Starts with and Ends with on a column or list that isn't text give a `#TYPE!` error, and the message names the fix: a Computed Column with `TEXT(@col, "@")`, or Cast to Text. They never compare against a number, date or true/false turned into text. This holds for every filter: the Filter nodes, List Filter and the *IFS criteria.

## Why

Comparing against a value turned into text made filter results depend on how the computer happens to print a number, and would have forced the desktop engine to copy that printing digit for digit forever. It is also invisible on screen, where a format change would look like a data change. The author chose this over keeping the text comparison or comparing formatted text. How it's built: the frame-verbs spec (filter).
