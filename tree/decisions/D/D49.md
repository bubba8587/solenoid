## Decision

**MUST:** `contains`, `startsWith` and `endsWith` on a non-text column or list is a `#TYPE!` configuration error, and the message names the fix: a Computed Column with `TEXT(@col, "@")`, or Cast to Text. It is never a stringified comparison; no filter path compares `String(cell)` of a number, date or logical. There is one gate on each side of the engine seam (`requireTextColumn` / `requireTextList` in `frameVerbs.ts`; `require_text_column` in `engine.rs`), called by every filter entry: the Filter verbs, List Filter and the *IFS criteria.

## Why

Comparing against `String(cell)` made filter results depend on JS's number-printing algorithm, and forced the Rust engine to mirror it digit for digit forever. A comparison against a hidden display string is also invisible in the UI, where a format change would read as a data change. The author chose this over keeping the display-string comparison or comparing app-formatted strings.
