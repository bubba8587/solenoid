## Decision

**MUST:** a node or operation name written in all capitals claims to be a function you can type into a formula. Such a name either runs in a formula, or is a real Excel function whose typed form sends you to this very node (GROUPBY, PIVOTBY). Every other name is Title Case.

## Why

A function's name is shown as you would type it, and it is also the node's title, so letter case is the one signal a reader has. An all-caps name you can't type is a false promise, and a Title Case name hides one you can.

## Consequences

- *Exception:* well-known acronyms (PCA, BMI, KPI and the like) and the Solenoid-only ISNULL stay in capitals though no formula runs them, and the flagship Convert stays Title Case though CONVERT does run. **Removed by:** nothing; an acronym is its name, and Convert is the node people know.
- The exact check and its allowlist: [[formula-language#Excel names on nodes]].
- **Reopen if:** formula names stop being written in capitals.
