## Decision

**MUST:** a node or op name written in all capitals claims to be a function the user can type into a formula. Such a name either runs in a formula, or is a real Excel function whose typed form sends the user to this very node (Excel's GROUPBY and PIVOTBY, which are Frame nodes here). Every other name is Title Case.

Two exceptions: well-known acronyms (PCA, BMI, TDEE, SVG, KPI) and the Solenoid-only ISNULL stay in capitals though no formula runs them, and the flagship Convert stays Title Case though CONVERT does run.

## Why

[[C19]] namingModel shows a function's formula name as the user types it, and the name is also the node's title ([[D22]] oneNamePerCard), so letter case is the one signal a reader has. An all-caps IS.TEST or REGEX reads as a function the user can type when they can't, and a Title Case "Transpose" hides one they can.

## Consequences

- The exact check and its allowlist: the formula-language spec, "Excel names on nodes".
