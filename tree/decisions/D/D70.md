## Decision

A function answers a blank when its result is undefined but nothing is wrong (too few points for a statistic, say), and an error only when an input is actually wrong. Excel errors on both.

## Why

Not enough data yet is the normal state of a growing table; making it an error would hide the one cell that's actually wrong.

## Consequences

- How it's built: [[formula-language]], with each difference from Excel in [[formulajs-divergences]].
- **Reopen if:** someone needs Excel's exact error on short data (an IFERROR guard that must fire).
