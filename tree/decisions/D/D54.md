## Decision

Solenoid never reads a relative date phrase (today, next friday, in 3 days, a bare weekday with no year) as a date. The one exception is the Date Input node, and only when Settings ▸ Data ▸ Relative dates is on (it's off by default). Such a Date Input raises a warning Alert when the day it lands on changes between calculations.

## Why

[[C44]] dateSerials makes a date a fixed calendar day. DATEVALUE, Cast, Frame and Table columns and every other place a date is read stay fixed, so a document never changes its answers because the day changed, unless the user asked for exactly that. The alert makes the one exception visible when it moves.

## Consequences

- **Reopen if:** the author wants DATEVALUE or a Frame column to follow the setting. The opt-in would then reach those places too, and the alert with it.
- How it's built: the formula-language spec (dates).
