## Decision

Solenoid never reads a relative phrase (today, next Friday, in 3 days) as a date, except on a Date Input that opts in, which warns when the day it lands on changes.

## Why

A date is a fixed calendar day, so a document shouldn't change its answers because the day changed, unless the user asked for that.

## Consequences

- How it's built: [[formula-language#Dates and times]].
- **Reopen if:** DATEVALUE or a Frame column should follow the opt-in too.
