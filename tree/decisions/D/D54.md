## Decision

Solenoid never reads a relative date phrase (today, next Friday, in 3 days, a weekday with no year) as a date. The one exception is a Date Input with Settings ▸ Data ▸ Relative dates turned on (off by default), and such a Date Input raises a warning alert when the day it lands on changes.

## Why

A date is a fixed calendar day ([[C44]] dateSerials), so a document shouldn't change its answers because the day changed, unless the user asked for exactly that. The alert makes the one exception visible when it moves.

## Consequences

- How it's built: [[formula-language]] (dates).
- **Reopen if:** the author wants DATEVALUE or a Frame column to follow the setting. The opt-in would then reach those places too, and the alert with it.
