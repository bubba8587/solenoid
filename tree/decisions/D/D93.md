## Decision

Wherever text becomes a value of a declared type (a table cell, a list item, a list field on a card, a note property from the vault), it is read one way, the way a Frame Input cell reads it. Text the type can't read is NaN, shown as `NaN`, never a silent blank; a date the type can't settle stays its error.

## Why

What was typed is the stored truth ([[C58]] tableInputRawText), and a reading that turns it into a blank hides that anything was typed at all, since a blank is a real missing value that totals skip. One reader means one rule to learn, so a user can predict what a cell holds.

## Consequences

- A bare number typed into a Date list is a day serial, and a NaN item counts in COUNT, as in a Frame column.
- How it's built: [[frame-verbs#Type inference]].
- **Reopen if:** Frame Input's cell reading changes; everything here follows it.
