## Decision

A Scatter, XY Line or Bubble chart reads its x, y, marker size, marker color, point text and series split from columns named in its options. Unnamed, the defaults stand: the first column is x and every later number column is a y series (Bubble: the first three number columns are x, y and size). A named column the data lacks is an error on the chart, never silently ignored.

## Why

Parametric curves and tables with metadata columns don't fit the 'first column is x, the rest are series' reading: a t, x, y table plots x and y against t, and a size or label column becomes one more series. Naming the role of each column is how pandas and seaborn plot a table, so it follows [[C96]] chartOptionsAreMatplotlib's vocabulary, and it keeps the chart one value ([[C100]] chartIsAValue) instead of a node whose sockets change with the data. Ignoring a misspelt column would draw a plausible wrong chart, so it errors.

## Consequences

- The keys are pandas' scatter names `x`, `y`, `s` and `c`, plus `annotate` (point text) and `by` (split into series), which have no matplotlib name.
- Merge Plots overlays XY plots on one numeric plane, so bars can't join an XY merge.
- **Reopen if:** the options move to structured fields per chart type, where a column picker could replace typed names.
