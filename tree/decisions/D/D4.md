## Decision

**MUST:** a membership set that encodes a property of a declaration (routing, exposure, capability) is derived from the declarations. A hand-written set is allowed only for facts that live nowhere else, and it must then be guarded by the behavior it produces ([[E1]] shapeGuardManualSets).

## Why

A hand-kept set fails open: nothing errors when a name is missing from it, and the behavior just changes silently. Ten functions (`T.TEST`, `F.TEST`, `Z.TEST`, `CHISQ.TEST`, `SUMX2MY2`, `SUMX2PY2`, `SUMXMY2`, `MODE.SNGL`, `PROB`, `SERIESSUM`) were missing from `RANGE_FUNCTIONS` and were applied element by element, each returning a believable wrong value.

## Consequences

*Exception:* `RANGE_FUNCTIONS` (`excelFormula.ts`) is still hand-kept for the Formula.js half of the formula surface, because Formula.js publishes no machine-readable signatures to derive it from. It is guarded by `rangeRouting.test.ts` ([[E1]] shapeGuardManualSets). **Removed by:** deriving argument shapes from a signature table, if one is ever written.
