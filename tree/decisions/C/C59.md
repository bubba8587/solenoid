## Decision

Data sorts and compares text by character code, the same on every machine, rather than by a language's rules.

## Why

Language-aware sorting follows the computer's settings, so the same document would sort differently from one machine to the next.

## Consequences

- How it's built: [[frame-verbs]], *String order*.
- **Reopen if:** users ask for language-aware sorting of their data.
