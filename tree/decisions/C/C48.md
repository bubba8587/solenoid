## Decision

There is one append node per shape, for lists, grids and tables, and each takes any number of inputs holding any kind of value. There is never one append node per kind of value.

## Why

Appending numbers and appending text is the same job; joining lists, stacking grids and matching table columns by name are different jobs.

## Consequences

- How it's built: [[formula-language]] (the append ladder) and [[frame-verbs#append]].
- **Reopen if:** one input can take several cables; it would replace the growing input rows.
