## Decision

Calculation is automatic, with a manual mode (F9) for heavy documents, and an edit recomputes only the nodes downstream of it. However a recompute is triggered (a full pass, a targeted one, a manual recalc or a live-data refresh), the values on screen are the ones a full clean pass would produce.

## Why

[[A5]]: Excel users expect automatic recalculation, with manual mode for heavy workbooks. The engine's pull-with-cache design ([[B10]] reactFlowView) makes a targeted pass cheap, but every way a cheaper pass can go wrong leaves a stale value beside fresh ones with nothing to mark it. So each rule under this one is an equivalence: a shortcut is allowed only if nobody can tell it was taken.
