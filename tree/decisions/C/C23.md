## Decision

Calculation is automatic, with a manual mode (F9) for heavy documents, and an edit recomputes only the nodes downstream of it. However a recompute is triggered (a full pass, a targeted one, a manual recalc or a live-data refresh), the values on screen are the ones a full clean pass would produce, never a faster answer that differs from it.

## Why

[[B19]] spreadsheetHabits keeps Excel's automatic recalculation, with manual mode for heavy work. Recomputing only what an edit touches is what keeps automatic recalculation fast enough to leave on. But a partial recompute that goes wrong leaves a stale value beside fresh ones with nothing to mark it. So each rule under this one says the same thing: a shortcut is allowed only if nobody can tell it was taken. How it's built: [[compute-pass]].
