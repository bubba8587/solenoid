## Decision

Every choice on a node is either an operation, a different function with its own name you can search for and type, or an argument, a setting of the node's one function. An aggregator such as SUM is usually an argument.

## Why

You search for and type an operation by name, and you don't for a setting, so blurring the two hides functions or names settings nobody would type.

## Consequences

- How it's built: [[node-classes#Formula registrations and op modules]].
- **Reopen if:** users search for aggregator names and don't find them.
