## Decision

Table Input saves exactly the text you typed, blank lines included, and works the table out from it each time.

## Why

If the saved text were rebuilt from the table, anything the reading step dropped would quietly vanish from the document too.

## Consequences

- How it's built: [[literal-input-editors]] and [[save-format]].

## Contest

### Contest 2026-09-26 by claude: keep wins

keep: saving the typed text and deriving the table each time is the only way no edit loses input (B12). opposite (save the derived table) drops whatever reading rejects. deletion leaves each literal editor to decide. Keep.
