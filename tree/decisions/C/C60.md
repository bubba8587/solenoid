## Decision

Running is one node, never separate Cumulative and Rolling nodes, and it has no switch between the two: its Window decides. A Window of 0, the default, runs from the start of the list; a Window of N covers the last N items. In a formula it is one function, `RUNNING(op, list, [window])`, with the kind of total typed as an argument.

## Why

A running total from the start and one over the last few items are the same job with one setting, so they are one node. A switch would be a second way of saying what the Window already says.

## Consequences

- The exact window rules: [[formula-language]], `running` and RUNNING.
- **Reopen if:** the two kinds need to treat the start of the list differently in ways one rule can't cover.
