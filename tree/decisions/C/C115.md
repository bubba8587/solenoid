## Decision

When a formula is committed with more `(` than `)`, the missing `)` are added at its end. It is a plain count, done when the formula is committed, rather than closing parentheses as you type.

## Why

Current Excel offers the same repair. Leaving off closing parentheses is the most common slip in a long nested formula, and it has one obvious fix, so an error for it only costs a trip back into the editor.

## Consequences

- The text never changes under the cursor, since nothing happens while typing.
- How it's built (what counts, which surfaces commit): [[formula-language#Syntax hints]].
- **Reopen if:** a formula surface commits on every keystroke, where the count would add parentheses mid-typing.
