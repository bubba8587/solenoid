## Decision

A function that is both a node and a formula is the same function on both: one piece of code, one answer.

## Why

There's no good reason to have two different versions of a function, one for the formula and one for the node, so they're the same.

## Consequences

- *Exception:* SHUFFLE shuffles with the one shared code, but its node and formula reshuffle at different moments (the node on recalc, the formula every time it runs), so their answers can't be compared. **Removed by:** nothing; any random function splits the same way.
- Where the shared code lives: [[formula-language]], *Shared kernels*.
- **Reopen if:** a node has to run somewhere the formula code can't.
