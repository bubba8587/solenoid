## Decision

When Solenoid writes a note's properties, it changes only the lines it means to change. Every other character of the note stays exactly as it was, and what it writes looks the way Obsidian writes it. Write Properties and every other write into a note share this one writer.

## Why

The vault belongs to the user, not to Solenoid ([[B1]] obsidianBet). A writer that read the properties in and wrote them all back out would change the spelling, order and quoting of every property on each save, and Obsidian users would see that as churn in their own files and in git. Having one writer is also the only way to check "nothing else changes" once, instead of hoping every write gets it right.

## Consequences

- Reading stays forgiving: any spelling Obsidian or a person writes is still read.
- How it's built: the reports-and-notes spec.
- **Reopen if:** Obsidian's own Properties writer changes its block style, or a write needs to restructure a note beyond its frontmatter.
