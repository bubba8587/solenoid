## Decision

When Solenoid writes a note's properties, it changes only what it means to change. Every other character of the note stays exactly as it was, and what it writes looks the way Obsidian writes it.

## Why

The vault belongs to the user, so a write changes only what it targets. Rewriting every property on each save would show up as churn in their own files and in git.

## Consequences

- How it's built: [[reports-and-notes#Write to Obsidian]].
- **Reopen if:** Obsidian changes how it writes properties, or a write needs to restructure a note beyond its properties.
