## Decision

A rule's exceptions are listed under that rule, never in a separate file, and each exception states the condition that would remove it.

## Why

No session remembers the last ([[B9]] rulesWithoutMemory), so an exception is only kept in check where the rule's readers see it. Written beside its rule, it is seen every time the rule is read, so the list stays counted and the pressure on it is to shrink; kept somewhere else, it goes unseen and accumulates. An exception that no condition could ever remove is a sign the rule itself was written wrong, and the fix is to rewrite the rule.
