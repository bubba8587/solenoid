## Decision

Work on a table or list costs time in proportion to its size, never its size squared, and drawing it costs no more than what fits on screen. Speed never buys a different answer.

## Why

Spreadsheet users expect a sheet of 100,000 rows to stay responsive while answers recalculate on their own. A path that does whole-table work once per row is instant on the 20-row examples every test uses and freezes for minutes on real data, so it ships unseen: a share-of-total column, a ranked Decision Matrix and a percent-of pivot each took that shape before anyone measured.

## Consequences

- How it's built: [[engineering#Performance]].
- **Reopen if:** an exact answer at some size can only be had by work that grows faster than the data, and the answer is worth the wait.
