## Decision

Solenoid's own formula functions have plain names with no prefix (no `SOL.`), each spelled exactly as the hint on the node's header shows it. A pack brings its own formula functions, offered while the pack is on.

## Why

A function has one name on both surfaces, and a user reads a name off a node and types it, so the two must match. A prefix would be one more thing to learn with nothing gained.

## Consequences

- A pack's functions keep working in a saved formula with the pack off; they are only hidden from autocomplete.
- How it's built: [[formula-language#Packs]] and [[formula-language#Derived names are unique]].
- **Reopen if:** a future Excel release collides with a bare name. That is a case-by-case rename, not a namespace.
