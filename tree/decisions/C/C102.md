## Decision

A blank cell in a bordered grid is filled by straight-line interpolation from the nearest square of known values, the answer MATLAB and SciPy give. Only with Forecast on (the default) does the grid also guess the gaps no square covers and extend the trend past its edges. With Forecast off, a lookup table stays a lookup table: a cell no square encloses stays blank.

## Why

A value between known values is a reading of the data, so it should match the tools people check it against. A value past the data is a guess, and a guess should only appear when you ask for one.

- **Reopen if:** a user needs a trend that isn't a straight line, or grids grow past what the capped search handles.
