## Decision

A blank in a table of values is filled in a straight line between known values: from the smallest box around it whose four corners are known, using the X and Y coordinates given beside the table, as MATLAB and SciPy do. The table is filled in past the edge of its data only when Forecast is on.

## Why

A value between known values is a reading of the data; a value past it is a guess, and a guess should appear only when you ask for one.

## Consequences

- How it's built: [[bordered-grid-fill]].
- **Reopen if:** a user needs a trend that isn't a straight line.
