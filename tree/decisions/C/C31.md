## Decision

**MUST:** every `documentStoreCore` transform returns a new `SolDoc` for each document it changes, and never mutates a document in place.

## Why

`documentStore.persist()` decides what to write by object identity (`_lastPersisted.get(id) === doc` skips the write). An in-place mutation still updates the screen, but the store sees the same object and never saves it, so the edit vanishes on the next reload ([[B12]] losslessSaves).
