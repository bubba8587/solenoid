## Decision

**MUST:** every rule node with a MUST is cited by the test that enforces it, or its Consequences carry an explicit `*Unenforced:*` line saying why it can't be checked. A bug fix ships with the check that would have caught it. The node never names its tests; the list of enforcing tests is derived from the citations (`dte show`, `dte coverage`).

## Why

What separates a spec from folk memory is whether anything fails when you break it ([[B9]] rulesWithoutMemory). `subsystem-invariants.md` § Pointer gestures shows the honest version of the alternative: the native-popup pointerdown swallow is labeled as kept on drag-prevention grounds, although the mechanism that first needed it died with the rete surface.

## Consequences

The labeling itself is pinned mechanically, because a test cites this node. Whether a citing test truly enforces its MUST is a job for a reader (backlog: citation coverage).
