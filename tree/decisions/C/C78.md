## Decision

As packs and subgraphs add power, keeping the UI obvious is the governing constraint:
- **Signal the exception, not the rule.** Locked is the silent default and gets no chrome; only an exposable or promoted port gets an accent affordance. Never stamp a lock icon on every locked cable or port.
- **Separate layout from structure.** A subgraph's arrangement can move freely while its wiring stays locked: being able to move something is not being able to rewire it.
- **Show the mode once, at the frame.** "You are viewing locked internals" is said once, as a tinted inner-canvas frame or a mode pill that reuses the existing canvas-lock and layout-pill chrome, never as badges on each cable.

## Why

Blender's node editor is the cautionary tale: powerful and illegible. The feature bends to the UI, not the reverse ([[B14]] oneDesignSystem). It is the same reason Conduit reroute nodes exist, so bundles of cables don't turn into spaghetti.
