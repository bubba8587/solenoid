## Decision

**MUST:** an empty argument slot (`POWER(2, )`, `SUM(a,,b)`) reads as Excel's blank for that parameter, the value Excel itself uses there: 0 for a number, FALSE for a logical, "" for text, 0 for a parameter that takes any value, and the argument left out where Excel treats an empty slot as omitted (TAKE's, DROP's and EXPAND's sizes). Every parameter of every function has this reading; none propagates as missing. An omitted trailing argument still takes the function's default.

## Why

A formula returns Excel's answer ([[A5]]), and an empty slot is something the user typed, not missing data, so it reads as the value Excel gives it.

## Consequences

- A blank *value* in a slot (a blank cell, a blank variable) is not an empty slot: it follows its input's role ([[D86]] blankRoles), so data stays missing ([[D36]] nullSkippedNotZero). `AVERAGE(2,)` is 1, as in Excel, while `AVERAGE(2, x)` with `x` blank is 2.
- An empty IF branch reads as 0, as in Excel: `IF(c,,x)` is 0 when `c` is true.
- The reading is shown wherever it isn't "" ([[emptySlotShowsItsValue]]).
- How it's built: [[input-roles#Empty slots]].
- **Reopen if:** Excel gives an empty slot a reading the declaration can't express, or the Expression grammar stops parsing an empty slot as `blank`.
