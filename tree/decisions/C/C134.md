## Decision

**A named function answers what its algebra, written out by hand, answers.** A function that is a shorthand for arithmetic or for a comparison gives the same answer as the formula it stands for:

- `SUM(2, x)` answers what `2 + x` answers, and `PRODUCT(2, x)` what `2 * x` answers;
- `AVERAGE(2, x)` answers what `(2 + x) / 2` answers;
- `MAX(2, x)` answers what `IF(2 > x, 2, x)` answers, and `MIN` likewise with `<`.

**What this leaf decides, for now:** only a value of the wrong type (text where a number is needed) and an error. A blank, a null, empty text (`""`) and NaN are **not** decided by this leaf; each gets its own ruling, and until then a function keeps whatever it does with them today. (A known open case: `AVERAGE(2, x)` with `x` blank skips the blank and answers 2, where `(2 + x) / 2` answers 1. This leaf leaves that alone.)

Worked example, with `x = "a"` (text) and `e` an error such as `NA()`:

| Named function | Written out by hand | Both answer |
|---|---|---|
| `SUM(2, x)` | `2 + x` | `#VALUE!` |
| `PRODUCT(2, x)` | `2 * x` | `#VALUE!` |
| `AVERAGE(2, x)` | `(2 + x) / 2` | `#VALUE!` |
| `MAX(2, x)` | `IF(2 > x, 2, x)` | `#TYPE!` |
| `SUM(2, TRUE)` | `2 + TRUE` | 3 |
| `SUM(2, e)` | `2 + e` | `#N/A` |

## Why

A function name is a shorthand people reach for instead of typing the algebra, so swapping one for the other should never change the answer. If `SUM` quietly skipped text that `+` refuses, rewriting `a + b` as `SUM(a, b)` would hide a wrong-type value instead of showing it, and nothing in a value's type should be dropped on its own ([[B17]] typedValueModel).

## Consequences

- Which error a function gives follows from the operator its algebra uses: arithmetic gives `#VALUE!`, as `2 + "a"` does; ordering gives `#TYPE!`, as `2 > "a"` does.
- TRUE and FALSE, and errors, already answered as their algebra does before this leaf; it changed nothing for them.
- **Reopen if:** the rulings on blanks, null, empty text or NaN are made (each extends or carves out of this leaf), or a function is found whose algebra people would not agree on.
