## Decision

`main` is release-only: it is production (the Vercel deployment and the tagged releases). All work lands on `develop`, and this standing order overrides any per-session directive to work on a `claude/*` branch.

## Why

There is one author and no release trains ([[B7]] preAlphaBreakFreely), so one development branch beside the production branch is all the structure needed. Per-session branches scatter work that the author then has to gather.

## Consequences

- The standing order and the release steps live in CLAUDE.md.
- **Reopen if:** there are several contributors or release trains.
