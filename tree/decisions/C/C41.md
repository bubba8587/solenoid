## Decision

The main branch is production only: the live site and the tagged releases. All work lands on the develop branch, never on per-session branches.

## Why

With one author and no release trains, one development branch beside production is all the structure needed, and per-session branches scatter work the author then has to gather.

## Consequences

- How it's done: the standing order and the release steps in CLAUDE.md.
- **Reopen if:** there are several contributors or release trains.
