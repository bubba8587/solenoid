## Decision

A Pivot's popup opens on a pivot table laid out the way Excel lays one out, with grouped labels that fold. The layout is only how the popup draws the output; every node downstream still reads the same plain Frame.

## Why

Excel users read a pivot as a pivot table, with grouped labels and merged headers, not as the flat sheet PIVOTBY spills. The output itself has to stay a plain Frame, so every other node reads it the way it reads any Frame.

## Consequences

- *Exception:* the ribbon's Subtotals and Grand Totals are the node's own totals setting, so changing them changes the Frame, as Configure Fields does. **Removed by:** totals becoming a setting of the view alone, so the Frame never carries them.
- The Grid, Cards and CSV views stay, showing the Frame as it is; Copy and Export copy the Frame.
- How it's built: [[table-popup#The Pivot view]].
- **Reopen if:** people want the pivot table itself, as laid out, to flow to other nodes.
