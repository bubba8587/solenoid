## Decision

The popup of a Pivot's output opens on a Pivot view that lays the Frame out as Excel's pivot table does: Compact, Outline or Tabular form, repeated or blank labels, blank rows between groups, banding and folding groups. The view only changes how the popup draws it; every node downstream reads the same Frame.

## Why

Excel users read a pivot as a pivot table, with grouped labels and merged headers, not as the flat sheet PIVOTBY spills, and the cross-tab has to stay a plain Frame so every other node reads it as it always has.

## Consequences

- *Exception:* the ribbon's Subtotals and Grand Totals are the node's own totals setting, so changing them changes the Frame, as Configure Fields does. **Removed by:** a totals choice the Frame never carries.
- The Grid, Cards and CSV views stay, showing the Frame as it is; Copy and Export copy the Frame.
- How it's built: [[table-popup#The Pivot view]].
- **Reopen if:** people want the pivot table itself, as laid out, to flow to other nodes.
