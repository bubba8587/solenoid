## Decision

Solenoid honors a folder's mdbase schema when it has one: it takes column types from it and refuses a write that breaks it. It writes no schemas and runs no mdbase queries.

## Why

mdbase is an optional extra that may still change before 1.0, so it's worth honoring but not worth building on.

## Consequences

- How it's built: `docs/node-coverage.md` § Vault Folder and Write Properties.
- **Reopen if:** mdbase reaches 1.0, or people with schemas ask for more.
