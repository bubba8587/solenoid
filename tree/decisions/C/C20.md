## Decision

**MUST:** a function that takes a whole list is routed past the element-wise broadcaster, and so is a function whose arguments are all scalars but whose result is a list.

## Why

Otherwise the evaluator calls the function once per element and returns N answers to a question that has one. A list-returning function broadcast that way builds a 2-D value that slips past the formula rank cap ([[C15]] matricesInFormulas).

## Consequences

- How each routed function prepares its arguments is [[formula-language#Range functions]].
