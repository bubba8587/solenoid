## Decision

In a Note or a Report you refer to a value by typing `{{ name }}` in Knap, Obsidian's template language; Solenoid has no reference syntax of its own. A plain `{{ name }}` shows the value as the canvas shows it (a table as a table, a chart as a chart), and anything more (a filter, a loop, a path) works on its underlying data. A Report's mail merge uses the same syntax.

## Why

One syntax to learn is simpler than two. Notes and Reports end up in Obsidian, so their text should use a template language Obsidian users already have rather than one only Solenoid reads.

## Consequences

- How a reference is shown on screen, in Obsidian and in exports: [[reports-and-notes]].
- **Reopen if:** a second reference syntax is wanted beside Knap, or `{{ name }}` stops showing what the canvas shows.
