## Decision

In a Note or a Report you refer to a value with `{{ name }}` in Knap, Obsidian's own template language; Solenoid has no reference syntax of its own. A plain `{{ name }}` shows the value as the canvas shows it.

## Why

Notes and Reports end up in Obsidian, so they should use a template language Obsidian users already have.

## Consequences

- How it's built: [[reports-and-notes#The bare tag and the internal span]].
- **Reopen if:** a second reference syntax is wanted beside Knap.

## Contest

### Contest 2026-09-27 by Claude Opus 5.5: keep wins

Opposite (Solenoid mints its own reference syntax beside Knap) makes a note written to the vault carry a syntax only Solenoid reads, against B1; Knap is Obsidian's own. Deletion: B1 does not by itself pick one syntax or say a bare tag shows what the canvas shows. Keep.
