## Decision

A Frame input's label names the columns it expects, in order (`From + To + Value`). An input that takes any columns gets a plain noun (`Data`). The label never states the shape; the socket already shows that.

## Why

The label is the only place you can see what columns a node wants before you wire it up.

## Consequences

- *Exception:* the λ-table nodes' inputs are named for the λ argument they bind (`Values (value)`, `value2 (optional)`), since that is what you need to know there. **Removed by:** those nodes binding by column name instead.
- The exact pattern is in [[node-classes]], *Frame input labels*.
- **Reopen if:** a node can show its expected columns some other way before it's wired.
