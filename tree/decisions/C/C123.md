## Decision

In the Decision Matrix and every node that scores the way it does (Decision Sensitivity, Choice Ladder), a criterion cell with no number (a blank, text, or a number that isn't finite) counts as the median of the other options' raw values on that criterion, taken before scaling. A criterion where no option has a number counts as 0 for all of them. A blank in a logical criterion stays FALSE, since a logical cell is a stated yes or no. A Choice Ladder's missing cost is filled the same way, from the kept options' costs, so an unpriced option is never free. Every filled value is named in a Filled in column, so a guess is never silent.

## Why

A missing score is unknown, not the worst or the best. Counting it as 0 made an unpriced option look cheapest whenever price was weighted against, so a gap in the data won the decision. The median treats it as a typical option instead, which is also how the author's Decision Matrix plugin for Obsidian reads it, so the two agree.

- How it's built: [[frame-verbs#Decision Matrix and Decision Sensitivity]].
- A deal-breaker never rules an option out on a missing score ([[frame-verbs#Decision Matrix and Decision Sensitivity]]).
- **Reopen if:** a decision needs a missing score to count against the option rather than as typical.
