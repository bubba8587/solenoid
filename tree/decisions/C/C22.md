## Decision

In a computed column, a bare name is the whole column and `@name` is this row's cell, as in Excel's table references. A whole column where one value is needed is an error pointing at `@`, never a silent read of this row.

## Why

That's how Excel's table references read, and any other rule gives believable wrong numbers instead of an error.

## Consequences

- How it's built: [[computed-columns]].
- **Reopen if:** Excel changes how its table references read.

## Contest

### Contest 2026-09-26 by claude: keep wins

keep: Excel's table references read bare as whole column and @ as this row, which B16 measures against; any single spelling for both makes SUMIFS(amt, cat, @cat) unwritable. opposite (bare = this row) silently gives believable wrong answers like share = 1.0. deletion leaves B16 to be applied per surface. Keep.
