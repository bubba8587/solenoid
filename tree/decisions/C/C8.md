## Decision

**MUST:** every user-visible fact (a label, a name, which operation a node performs, how many inputs it takes) is written down in exactly one place, and every other place that shows it reads it from there. Copying a value into a second place is a defect even while the two copies agree.

## Why

Nothing keeps two copies equal, so they are already wrong; nobody has looked yet. The IS.TEST node once showed ISBOOLEAN while the Add menu search offered ISLOGICAL, so a name read off the node couldn't be found in the menu. Its list of operations had been written out twice, once for the node and once for the menu.
