## Decision

Each filter node has one job. List Filter tests a list against its own values only; the parallel-list mask it once had is deleted. Filtering a table goes through the frame Filter. SUMIFS and its siblings (COUNTIFS, AVERAGEIFS, MINIFS, MAXIFS) are the task-shaped conditional aggregate: one Frame input plus criteria rows, following the aligned-columns rule.

## Why

The parallel-list mask made List Filter's behavior impossible to read from the card. With one job per filter node, what each does stays readable, and conditional aggregation already has its Excel-shaped home.

## Consequences

- **Reopen if:** evidence that filtering by a parallel list without aggregating is common enough to outweigh the mask's opacity. Per-cell 2-D filtering stays out regardless; the way to spell it is TOCOL followed by Filter.
