## Decision

**MUST:** a node that changes something outside the app for good (a write to disk or to a vault) acts only when the user presses its Run button, or on an explicit command-line run, and only while it is armed; never when the graph recalculates. Until then it shows a preview. Arming is never saved, so a node always arrives disarmed.

## Why

Opening a document must never act outside the app, so a write that can't be undone waits for a deliberate press.
