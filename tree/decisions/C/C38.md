## Decision

**MUST:** a node that changes something outside the app for good (a write to disk or to a vault) acts only when the user presses its Run button, or on an explicit command-line run, and only while it is armed; never when the graph recalculates. Until then it shows a preview. Arming is never saved, so a node always arrives disarmed, whether from opening a file, pasting or a restored placeholder.

## Why

An irreversible effect has to be a deliberate act. Acting on recalculation would write to disk on any edit, and a saved arm flag would let merely opening a shared file write to the reader's disk. Vault writes ([[B1]] obsidianBet) and safe reopening ([[B12]] losslessSaves) both depend on this.
