## Decision

Group membership changes only on an explicit gesture: dragging a node in or out, the Group action on a selection, or a manual box resize over a node. Autofit wraps the box around the existing members and never re-derives membership. A collapsed group never gains a member. Membership is exclusive and stable: a node belongs to at most one group and keeps it while its center is inside, so an overlapping group cannot steal it.

## Why

[[B14]] oneDesignSystem: the canvas changes only when the user asks. Membership worked out from where boxes happen to sit would pull in any bystander a resized box covers, and a node dropped over a collapsed group, drawn small with its members hidden, would join it and vanish the next time it collapsed. Both are a membership change the user did not ask for.

## Consequences

- A Format Controller docked to a node belongs to whatever group its node belongs to; it never joins or leaves on its own.
- How each gesture changes membership is in the group-expand-push spec (§ Who is a member).
- **Reopen if:** an explicit "absorb everything under the box" action is wanted (then it is its own gesture, not a side effect).
