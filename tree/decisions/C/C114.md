## Decision

Add a mobile-friendly, deterministic Cards layout as an option in the table popup editors. The layout is inferred by rules that read the underlying data's content, type, format and column structure. These Cards work with the Record node, which draws the same cards as a chart.

## Why

No matter how the layout is tweaked, grid data doesn't read well on a narrow screen. A Cards layout adds a lot of value to the mobile offering.

## Consequences

- Grid stays the default; Cards is an option.
- **Reopen if:** people want to write card layouts themselves.
