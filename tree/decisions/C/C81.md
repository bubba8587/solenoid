## Decision

Every reference to a leaf, in the code, the docs and the other leaves, is written as an Obsidian link, `[[ID]]` (optionally followed by the leaf's name), and so are the links between leaves (parents, what a leaf replaced, what it conflicts with), instead of DTE's own citation form.

## Why

With the repo opened in Obsidian, every leaf's parents, replacements and the docs that cite it become links the author can click, backlinks and edges in the graph view, with no plugin ([[B1]] obsidianBet). [[B8]] treeIsTheHome makes the tree the one home for rules, so it has to be readable where the author reads. DTE's own citation form means nothing to Obsidian, and the tool reads both forms, so the link form costs nothing.

## Consequences

- The vault is `tree/`, holding the leaves and the specs side by side, so a spec and the leaves it serves link to each other in one graph. Specs are Obsidian notes too. The author's call.
- The vendored DTE rules stay a verbatim copy and still describe DTE's own form; Solenoid's difference, and how the tool is patched for it, is in `docs/dte.md` § Wikilinks.
- **Reopen if:** upstream DTE adopts a different link syntax, or the repo stops being read from Obsidian.
