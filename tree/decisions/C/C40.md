## Decision

**MUST:** every module store holding per-node state registers both `registerNodeForget` (run on the `noderemoved` path) and `registerNodeForgetAll` (the bulk reset on rebuild) with `nodeStoreRegistry`, at module scope. The rebuild path calls `forgetAllNodes()` once; no store is cleared by hand in persistence, and no per-node cleanup is wired by hand in Canvas. The sanctioned alternative is a store that holds one transient id (an open popup or overlay) rather than a per-node map.

## Why

Every ad hoc alternative was tried, and each one decayed. Four stores held node-keyed maps with no cleanup, so dead ids lingered until reload. Persistence listed four more stores' `clear()` calls by hand beside the registry's bulk reset. Canvas wired the standoffs' per-node cleanup unconditionally, paying for a per-node scan during rebuilds, which is the cost the registry's `isGraphRebuilding` skip exists to avoid. The isolate store's miss was a visible bug: nothing exited isolate on a document switch, so the stale focus set dimmed the entire new graph.
