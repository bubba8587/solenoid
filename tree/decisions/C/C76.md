## Decision

By default a pack node is a ready-made formula with its description (name, help, input names and units, the matching Excel function), written as data rather than new code. A pack says, node by node, when it needs custom logic instead: a compiled library, solving or iterating, looking values up in a bundled dataset, or a custom control.

## Why

Formula nodes keep packs cheap and safe, and they get units right because the formula engine already understands them. Custom code is harder to trust from a third party and often only works on desktop, so it's the short list that gets scrutiny.

## Consequences

- A document that uses a formula pack node still computes with the pack switched off: the node reopens as a locked Expression.
