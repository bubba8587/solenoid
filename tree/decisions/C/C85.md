## Decision

Expanding a collapsed group moves its neighbors aside with a deterministic push over plain boxes: rails, then clear, then a residual clear, then cascade. The push is recorded as absolute before-and-after positions, together with the set of groups that contributed, and it is inverted exactly once every contributor is collapsed again or deleted. ELK never runs in this path. Manual moves win: a node the user has dragged since the push stays where they put it, and only a real drag (not a click) invalidates a record.

## Why

Rails and clears are deterministic, respect deliberate placement and can be undone exactly, while ELK re-derives every position globally and cannot snap back. Absolute records make restores independent of order when several groups are expanded at once.

## Consequences

- `setGroupsCollapsed` is the one entry point for the toggle (chevron, outline panel, hotkey). It measures the collapsed card sizes before the flip, because the stretch seams start from them.
- A within-group Tidy that grows its box reuses the same engine without a record. A Tidy is a deliberate action, so that displacement is permanent and neighbors never rush back on collapse.
- A programmatic move between two pushes (Tidy, Cleanup, align) voids the old record, and the next push starts a fresh one from the current position.
- Standoff corrections fold into the same records, so a cluster restores as one block ([[C89]] standoffsSolveLast).
- **Reopen if:** users want a global re-layout on expand rather than minimal disturbance.
