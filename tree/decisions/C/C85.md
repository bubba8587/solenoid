## Decision

Expanding a collapsed group moves its neighbors aside by a fixed push that gives the same result every time, and collapsing it again puts them back exactly; never an automatic re-layout of the canvas. A node the user has dragged since the push stays where they put it, and only a real drag, not a click, counts. How the push runs and how it is undone is in [[group-expand-push]].

## Why

[[B14]] oneDesignSystem makes the layout part of what the user reads, and where they put a node is deliberate. A whole-canvas re-layout on every expand would move nodes the user placed and could not snap back when the group closes; a fixed push touches only what is in the way and can be undone exactly. A manual move wins because it is the one placement the user chose.

## Consequences

- `setGroupsCollapsed` is the one entry point for the toggle (chevron, outline panel, hotkey). It measures the collapsed card sizes before the flip, because the stretch seams start from them.
- A within-group Tidy that grows its box reuses the same engine without a record. A Tidy is a deliberate action, so that displacement is permanent and neighbors never rush back on collapse.
- A programmatic move between two pushes (Tidy, Cleanup, align) voids the old record, and the next push starts a fresh one from the current position.
- A group being pushed clears by geometry and never toward its cables, because a group chasing its connections piles interconnected groups onto one spot when several expand at once.
- Standoff corrections fold into the same records, so a cluster restores as one block ([[C89]] standoffsSolveLast).
- **Reopen if:** users want a global re-layout on expand rather than minimal disturbance.

## Contest

### Contest 2026-09-24 by Claude Opus 5.5: keep wins

Opposite (ELK or a global re-layout on expand) cannot invert exactly and moves cards the expansion never touched; deletion leaves B10 reactFlowView unable to say why expand must be undoable. Keep: a deterministic push over plain boxes is headless per B10 and reverses exactly.
