## Decision

The popup of a Describe node's output opens on a Dashboard view: one tile per column of the frame Describe read, with its fill, its key numbers and a small chart drawn by the app's own chart renderers. A number column shows a histogram and a line of its values in row order, a date column a histogram over its span, and a text or logical column its most common values; a number column with only a handful of values lists them too, since a histogram of two years is two bars and a gap. As with the Pivot view ([[C127]] pivotView), the summary Frame is unchanged, and the Grid and CSV views show it as it is.

## Why

A table of means and quartiles says what a column holds only to someone who reads statistics; a histogram and a list of the top values say it at a glance. Putting them on Describe keeps one node for "what's in this data" instead of a second node that computes the same thing.

## Consequences

- The tiles come from the same pass that computes the summary, kept beside the Frame as the Pivot view's layout is, so no other node sees them.
- A chart's expand button opens it full size in the chart popup, with axes.
- How it's built: [[table-popup#The Dashboard view]].
- **Reopen if:** people want the dashboard on the canvas, on the node's card or as a chart value another node can take.
