## Decision

The popup of a Describe node's output opens on a Dashboard view: one tile per column of the data Describe read, with how full it is, its key numbers and a small chart of what it holds. As with the Pivot view ([[C127]] pivotView), the summary Frame itself is unchanged, and the Grid and CSV views show it as it is.

## Why

A Frame of means and quartiles says what a column holds only to someone who reads statistics; a histogram and a list of the top values say it at a glance. Putting them on Describe keeps one node for "what's in this data" instead of a second node that computes the same thing.

## Consequences

- The tiles come from the same pass that computes the summary, kept beside the Frame as the Pivot view's layout is, so no other node sees them.
- A chart's expand button opens it full size in the chart popup, with axes.
- How it's built: [[table-popup#The Dashboard view]].
- **Reopen if:** people want the dashboard on the canvas, on the node's card or as a chart value another node can take.
