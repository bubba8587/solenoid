## Decision

Every node can be added from the Add menu in some form: a leaf of its own, an op row under its card, or a search row. How the menu is arranged (categories, order, which forms get their own row, what search alone reaches) is the author's hand design, recorded in [[add-menu]], not generated.

## Why

The author's call (2026-11-04): a node nobody can add might as well not exist, so reaching every node is the rule; how the menu reads is a design judgment the author makes by hand, so one spec holds every one of those choices and no further leaf is needed for them.
