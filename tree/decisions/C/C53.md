## Decision

Query, Solenoid's answer to Power Query, is an ordinary composite node set up in advance, never a new kind of node with its own step types or its own way of saving. Its steps are the usual table nodes placed inside it, and it runs only when you press Refresh.

## Why

We want one node per job, and a query is just a composite that runs when you ask, so it is a setting of the node we already have.

## Consequences

- How it's built: [[composite-nodes#Manual refresh and Query]].
- **Reopen if:** people need to preview or hold the result of each step, or need something a composite's inputs and outputs can't express.
