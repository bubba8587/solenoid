## Decision

A LAMBDA wired into MAP, REDUCE and the like matches its parameters to that function's values by name, not by position as in Excel. A name the function doesn't offer is an error. The constants pi, tau, e and phi keep their meaning inside a LAMBDA too, so a parameter with one of those names is an error.

## Why

On a canvas you can't see the order of the wires, so matching by position would quietly swap arguments. Since parameters match by name, a name has to mean one thing wherever it sits.

## Consequences

- How it's built: [[formula-language]].
- **Reopen if:** the canvas starts showing an argument order people can see and rely on, or people need short parameter names that clash with a constant.
