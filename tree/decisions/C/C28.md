## Decision

**MUST:** a class declares `literals` or `stringLiterals` exactly when its card edits those values inline. Loading restores the maps only onto classes that declare them, so a save or a seed cannot hardcode a value the user can't see.

## Why

[[B12]] losslessSaves means a document reopens as the user saw it. A literal restored onto a card that never shows it is a hidden value: it computes, but nobody can see or edit it.

List Input keeps its typed rows as its only editor, by the author's call. A raw-row popup editor and a dummy chip were once added to it unasked, and each later fix broke the list popup a new way, so they were removed; `tests/graph/listInputChip.test.ts` pins the plain form.
