## Decision

**MUST:** a node saves a typed-in value only where it shows that value for editing. Opening a document restores such values only onto nodes that show them, so neither a save nor a sample document can plant a value the user can't see.

## Why

[[B12]] losslessSaves means a document reopens as the user saw it. A saved value restored onto a node that never shows it is hidden: it computes, but nobody can see or edit it.

## Consequences

- List Input keeps its typed rows as its only editor, the author's call: no raw-row popup editor and no extra chip on it ([[literal-input-editors]] § List Input is not one of them).
