## Decision

**MUST:** a node saves a typed-in value only where it shows that value for editing. Opening a document restores such values only onto nodes that show them, so neither a save nor a sample document can plant a value the user can't see.

## Why

A document should reopen as the user saw it. A saved value on a node that never shows it would still compute, and nobody could see or edit it.

## Consequences

- List Input's typed rows are its only editor; its popup only views them.
- How it's built: [[inline-literal-maps]] and [[literal-input-editors]].
