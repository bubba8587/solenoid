## Decision

**MUST:** a typed edit takes effect when the user presses Enter or clicks away, never on each keystroke. Until then the text is a draft that only the field sees. Escape throws the draft away, and one committed edit is one undo step. Picks that are one gesture (a dropdown, a checkbox, a slider) apply at once.

## Why

[[B19]] spreadsheetHabits: an Excel cell commits when you leave it, and that is the habit users bring. Committing on every keystroke would recalculate the graph on every character, fill undo with half-typed values, and let a half-typed number flow downstream as a wrong answer ([[B14]] oneDesignSystem keeps every field to this one rule).

## Consequences

- Renaming a node works the same way: the name changes when you press Enter or click away.
- A formula or script is saved once, when its field or popup closes. Saving it redraws the node's inputs, so a half-typed formula would drop a variable mid-edit and unplug the cables already wired to it.
- **Exception:** the descriptions of a formula's variables in the formula popup save on each keystroke. They are notes, not part of the formula, and never cause a recalculation. It goes if a description ever feeds a computation.
- **Exception (the author's call):** the Slider's playback speed applies on each change. It only drives the play timer and never causes a recalculation. It goes if speed ever feeds a computation.
- An open draft is never lost when the user switches documents, saves a file or closes the window: each of those commits every open draft first. The background autosave does not, since it would commit a field while the user is still typing.
- How it's built, and the check that enforces it: the components floor spec (`tree/specs/floors/components.md`, rule 2).
- **Reopen if:** a live-preview field is wanted. It would then preview the draft, as the number scrub does, and still commit once.

## Contest

### Contest 2026-09-24 by Claude Opus 5.5: keep wins

Opposite (commit per keystroke) leaks half-typed values: the Image URL fetched per character and a first keystroke dropped the attached file; a Note body or Report template was read half-typed by any unrelated recompute and by the autosave. Deletion: B14 says nothing about commit timing, so the rule would go unenforced. No variant beats keep; the sweep now also flags onChange that writes the node or saves.
