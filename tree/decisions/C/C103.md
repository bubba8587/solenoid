## Decision

Content that crosses the app's boundary is made safe at the one place it crosses:

- an exported table cell that a spreadsheet would run as a formula is made harmless;
- an SVG image that is pasted, uploaded or fetched is cleaned of anything that could run or phone home;
- a link in a Note or Report opens in the system browser, never inside the app;
- a document from someone else fetches nothing over the network until you allow it, once per document.

## Why

Opening someone else's document should never act or reach out on its own. One guard per crossing means a new way in or out gets the guard for free instead of forgetting it.

## Consequences

- How each guard is built: [[reports-and-notes]] (§ What is sanitized, and where), [[table-popup#Copy and export]] and [[live-connections#The network gate]].
- **Reopen if:** something needs to run untrusted script on purpose, or documents can carry an origin the app can trust.
