## Decision

Content that crosses the app's boundary is guarded at the one seam it crosses:

- A CSV cell that a spreadsheet would evaluate on paste or open is escaped on every export (`csvSafety.ts`), whether it leaves through the popup's Copy or Export or through the Write File sink.
- SVG markup that a user pastes, uploads or fetches is sanitized before it is inlined into the live page or saved (`svgSanitize.ts`).
- A link inside rendered markdown opens externally and never navigates the app's own webview (`externalLinks.ts`).
- A document that was not authored on this machine fetches nothing over the network until the user allows it for that document (`docMetaStore.networkAllowed`, asked once per document); a document authored locally fetches on load as usual. Every fetch path (Connection nodes, data feeds, the SVG Picker's URL source) asks this one gate.

## Why

Web readers open shared documents ([[B2]] webTryDesktopFull), and a Note carries whatever its author or their vault put in it; a shared file could also contact arbitrary URLs the moment it opens, or leak data through them. Each guard is one rule at one seam rather than a check in every caller, so a new export path or a new markdown surface inherits the guard instead of forgetting it.

## Consequences

- A new way for text, markup, a link or a fetch to leave or enter the app routes through the existing seam and does not grow its own check or prompt.
- **Reopen if:** a surface needs to run untrusted script on purpose (a sandbox is then the seam, [[C66]] scriptNode), or documents carry a provenance the app can trust (a signed origin), which would let the network gate choose its default per source.
