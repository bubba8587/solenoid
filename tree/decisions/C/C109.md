## Decision

On Linux the desktop app draws its own minimize, maximize and close buttons and its own window edges for resizing, instead of using the window plugin's. On Windows it keeps the ready-made title-bar buttons from the window plugin it uses (decorum). The mechanics are in [[layout-chrome]].

## Why

On Linux the ready-made buttons don't work: the system title bar stays, the buttons appear twice, and minimize does nothing. The desktop is the full product ([[B2]] webTryDesktopFull), so its window buttons have to work.

## Consequences

- **Reopen if:** the plugin fixes all three problems on Linux, or Windows moves to the app's own buttons too, which would give up the Windows 11 layout menu that appears when hovering maximize.
