## Decision

A change the author makes in the vault is a work list an agent must process, never a silent edit. It reaches agents in one of three forms:

- a note dropped in `tree/decisions/outbox/`;
- one of four flat action tags on a node, `ratify`, `retire`, `contest` or `ask`, either in the tags property or as an inline hashtag (the author ruled out nested tags);
- a `ratified_by` typed into the Properties pane.

A bare diff is not one of them. `python tools/dte.py outbox` lists the items with the exact command each needs, validate prints their count, and `outbox --done <ID|slug>` clears one once it is processed. Every agent session starts by processing the outbox.

## Why

[[B1]] obsidianBet makes Obsidian the author's desk, and the author edits there without a terminal. [[B8]] treeIsTheHome makes the tree the one home, so a change the author wants must land in the tree with provenance (a History line, a ledger line, the owner-kept ratified list) rather than sit as an anonymous diff. An anonymous edit cannot be told apart from an agent's own unfinished work, and validate already lists changed nodes, so a bare diff carries no instruction. The inbox already carries requests from agents to the author; the outbox is the other direction. Tags and a folder are the two gestures Obsidian makes cheap, and git already knows what changed, so no watcher or plugin is needed.

## Consequences

- The author's word is the authorization. An edit or tag from the vault is processed under upstream DTE's B25 (what a node justifies, you do), with `authorized_by` naming the author where the node is human-held or above the agent's ring, and it is never re-asked.
- Nodes carry `aliases` from their `name`, so `[[branchModel]]` resolves in the vault; a citation the tool counts still uses the ID. Obsidian's `aliases`, `tags` and `cssclasses` are known fields.
- The parser accepts Obsidian's rewrites: `null` as empty, block lists and reordered keys. A ratification made in the working tree does not fail the human-held check, because the node at HEAD was not human-held.
- `tree/decisions/DTE.base` gives the Outbox, Unratified, Contested, Inbox and All views in Obsidian.
- **Reopen if:** a DTE plugin for Obsidian processes the outbox itself, or upstream DTE ships its own channel from human to agent.
