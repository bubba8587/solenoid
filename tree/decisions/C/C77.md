## Decision

A pack node built from several nodes is a composite with fixed inputs and outputs, never a kind of Group. A pack node built from one formula looks the same from outside: named inputs with their limits and defaults, named outputs, and a locked inside.

## Why

A pack node is a promise of named inputs and outputs, and a composite is how several nodes are packaged behind such a promise. A Group has no inputs or outputs and computes nothing, so it can't make that promise.

## Consequences

- An input's limit is a setting on the input, never extra nodes hidden inside.
- How it's built: [[composite-nodes]].
