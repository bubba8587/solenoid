## Decision

The node Inspector shows static reference material for the selected node and its current configuration: the Function Reference entry derived for it, plus the node's socket roster described in plain English (`SOCKET_TYPE_LABELS`). It never shows live values and never shows live connections.

## Why

The author's call. Live values already have a home (the card and its popups), and so do live connections (the canvas and the Cable inspector). A third live view would be a second copy of each, drifting from the one the user acts on ([[C8]] declareOnce).

## Consequences

- **Reopen if:** a workflow needs a live readout that the card and the Cable inspector cannot give.
