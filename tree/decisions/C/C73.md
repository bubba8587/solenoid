## Decision

The Inspector shows reference material for the selected node as it is set up: its Function Reference entry, plus a plain-English list of its inputs and outputs and what type each takes. It never shows live values and never shows live connections.

## Why

[[B14]] oneDesignSystem gives each thing on screen one home. Live values already have one (the node and its popups), and so do live connections (the canvas and the Cable inspector). A third live view would be a second copy of each, drifting from the one the user acts on ([[C8]] declareOnce).

## Consequences

- **Reopen if:** a workflow needs a live readout that the node and the Cable inspector cannot give.
