## Decision

The Inspector shows reference material for the selected node as it is set up: its Function Reference entry and a plain-English list of its inputs and outputs and the type each takes. It never shows live values or live connections.

## Why

Live values already show on the node and its popups, and live connections on the canvas and the Cable inspector. A third live view would only repeat them, and could disagree with the one you're working in.

## Consequences

- **Reopen if:** a workflow needs a live readout that the node and the Cable inspector cannot give.
