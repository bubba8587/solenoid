## Decision

A standoff is a spacing you set between two things, and no layout action may leave it broken: after a drag, expand, collapse, fit or Tidy, the standoffs are settled last. Things tied together by standoffs move as one block in every layout action.

## Why

A spacing you set that a layout step can quietly break isn't worth setting. Moving tied things as one block keeps a Tidy from pulling them apart only to snap them back.

## Consequences

- How it's built: [[standoffs]].
- **Reopen if:** standoffs need to tie group members or conduits.

## Contest

### Contest 2026-09-24 by Claude Opus 5.5: keep wins

Opposite (bands as soft hints any pass may break) makes a declared constraint meaningless; deletion leaves nothing saying clusters move rigidly. Keep. The no-overlap pass that now follows the solver moves each cluster as one unit, so it never breaks a band and the rule holds.
