## Decision

A chart is a value, like a number. A chart node's output describes the whole figure (what kind of chart, its data and its options), so it travels along a cable, saves with the document, and can be drawn anywhere a value can be shown: a Display, a Report, a popup.

## Why

A chart shown only on the node that made it can't go into a Report, show in a Display, or take a format downstream the way any value does ([[C118]] formatTravelsWithValue). As a value, it goes wherever a number goes.

## Consequences

- The chart describes its data, not its pixels, so the same figure draws at any size, from a small chip to a full popup.
- How each kind of figure is drawn: [[chart-figures]].
- **Reopen if:** figures need to write edits back into their data. They would then need an identity, not just a value ([[C71]] noBarEditing).
