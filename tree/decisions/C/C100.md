## Decision

A chart is a value, like a number: it travels along a cable, saves with the document and shows anywhere a value can.

## Why

A chart that lives only on the node that drew it can't go into a Report or a Display; as a value it goes wherever a number goes.

## Consequences

- How it's built: [[chart-figures]].
- **Reopen if:** charts need to write edits back into their data.

## Contest

### Contest 2026-09-26 by claude: keep wins

keep: a chart that is a value can be shown, embedded and formatted anywhere (B17 counts it as a value). opposite (chart as the node's private drawing) breaks Reports and Displays downstream. deletion leaves B17's 'a chart is a value' unimplemented. Keep.
