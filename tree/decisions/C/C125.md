## Decision

Decision Sensitivity has a Flip points mode. For each criterion, holding every other weight still, it finds the nearest weight above and below the current one at which a different option would come first, and names that option. The search never takes a weight past zero, since that would turn a cost into a benefit, and an option a deal-breaker rules out never wins.

## Why

The question behind a weighted score is how sure it is. A flip point answers it for each weight in the units the person set: if Light's 2 only has to drop to 1.6 for another apartment to win, the call is close on Light and worth a second look; if no weight short of zero changes it, it isn't. Named scenarios answer only for the scenarios someone thought to write, and a spread of random weights is harder to read than one number per criterion.

## Consequences

- How it's built: [[frame-verbs#Decision Matrix and Decision Sensitivity]].
- It takes the place of nudging every weight by ±10% as named scenarios.
- **Reopen if:** people need to know how two weights moving together change the winner.
