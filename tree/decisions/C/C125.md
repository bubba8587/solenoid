## Decision

Decision Sensitivity has a Flip points mode. For each criterion it takes the Weights table and finds, holding every other weight, the nearest weight below and above the current one at which a different option would take first place, and which option. A criterion's weight never crosses zero in the search, since that turns a cost into a benefit, and an option ruled out by a deal-breaker can never win.

## Why

The question behind a weighted score is how sure it is. A flip point answers it for each weight in the units the person set: if Light's 2 only has to drop to 1.6 for another apartment to win, the call is close on Light and worth a second look; if no weight short of zero changes it, it isn't. Named scenarios answer only for the scenarios someone thought to write, and a spread of random weights is harder to read than one number per criterion.
