## Decision

How a value is shown (its decimal places, percent, currency or date style) is set by a node on the canvas, the Format Controller, and belongs to the value: it travels down the cables with it, rather than living in a cell's styling where nothing downstream can see it. A unit is set with a node and belongs to the value in the same way ([[C25]] firstClassUnits).

## Why

We want a value to know what kind of thing it is ([[B17]] typedValueModel), and how it's meant to be read is part of that. Setting it with a node keeps it on the canvas, where you can see where it came from and change it.

## Consequences

- Which controls a Format Controller offers for each kind of value: [[format-model]].
- **Reopen if:** formatting needs to change cell by cell inside one list or column (conditional formatting), which a format on the value can't express.
