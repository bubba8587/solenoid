## Decision

How a value is shown (decimal places, percent, currency or date style) is set by a node on the canvas, the Format Controller, and travels down the cables with the value instead of living in a cell's styling.

## Why

How a value is meant to be read is part of what it is. Setting it with a node keeps it on the canvas, where you can see and change it.

## Consequences

- How it's built: [[format-model]].
- **Reopen if:** formatting needs to change cell by cell inside one list or column (conditional formatting).

## Contest

### Contest 2026-10-06 by Claude Opus 5.5: keep wins

Keep. Opposite (format as hidden per-cell styling) leaves a value's reading invisible beside its type, which B17 typedValueModel's typed display needs on the canvas. Deletion leaves B17 unable to say where a format lives. A source card that sets its own value's format (Value Input) is still a node on the canvas setting it, and the format still travels the cables, so keep covers it.
