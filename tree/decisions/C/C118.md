## Decision

How a value is shown (decimal places, percent, currency or date style) is set by a node on the canvas, the Format Controller, and travels down the cables with the value instead of living in a cell's styling. It carries on through each step that keeps the value's meaning and stops at one that doesn't: adding two percentages is still a percentage, multiplying them isn't. A nearer Format Controller always wins, and a number nobody formatted shows the same way everywhere.

## Why

How a value is meant to be read is part of what it is, so the format follows the value as far as it still describes it and no further. Setting it with a node keeps it on the canvas, where you can see and change it. The same number shown different ways in different places makes you doubt which one is the value.

## Consequences

- A number nobody formatted shows a whole number as it is, anything else to the Decimal places setting (4 by default) with trailing zeros dropped, and extreme sizes in scientific notation ([[format-model#Styles]]).
- *Exception:* the Constant cards, which exist to show a constant's precision, and chart axis ticks, which the chart lays out, keep their own rule. **Removed by:** nothing; each has its own job.
- How it's built: [[format-model]], and which steps carry the format in [[unit-flow#What carries the format]].
- **Reopen if:** formatting needs to change cell by cell inside one list or column (conditional formatting), or one surface needs a different default from the rest (it then takes a Format Controller, never its own constant).

## Contest

### Contest 2026-10-06 by Claude Opus 5.5: keep wins

Keep. Opposite (format as hidden per-cell styling) leaves a value's reading invisible beside its type, which B17 typedValueModel's typed display needs on the canvas. Deletion leaves B17 unable to say where a format lives. A source card that sets its own value's format (Value Input) is still a node on the canvas setting it, and the format still travels the cables, so keep covers it.
