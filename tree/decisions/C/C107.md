## Decision

Solenoid ships an Obsidian plugin, Solenoid Properties, that shows Solenoid's own kinds of value inside a note's properties: each appears as the app's own chip and opens the app's own editor, while the note keeps plain YAML.

- The chips and editors are the real app components, never redrawn or forked for the plugin; a need they lack becomes an option on the component.
- They are styled by the app's own look, and the plugin never restyles Obsidian around them.
- A property is plain YAML in the shape Solenoid's note reader already reads. What needs a graph (computed columns, λ, units, pins, saved formats) is left out rather than faked.

The mechanics, the type table and every difference from the full app are in [[obsidian-plugin]], and the code is built to that spec.

## Why

[[B1]] obsidianBet has Solenoid write tables and cubes back into notes, but in Obsidian those read as raw YAML, so the values Solenoid writes are the ones a reader can't see. [[B3]] sameNodeEverywhere says a node is never redrawn outside the canvas, so the plugin bundles the real components, which keeps the note and the canvas identical by construction where a redraw would drift with every change.

## Consequences

- The author's rulings on the plugin's surface, each specified in [[obsidian-plugin]]: a chip is always `sm`, because `md` overpowers a property row; the settings page shows no sample chips, because a chip over made-up data is bogus; a list property opens a one-column raw grid with Save, a fine workaround while the app has no list editor; every popup wears its value type's socket color, since no node launches it; a frame column's picked type is kept and Solenoid reads it, because the pick is what stops the guessing games, and a column nobody has typed takes its first guess from the YAML values' own types, never their text, because re-inferring from the text on every open made the type selector a lie and let a Save turn a Text `"0012"` into 12.
- **Reopen if:** a component in the bundle needs a shim that changes what it draws (the component then gets a real seam instead), or Obsidian drops `metadataTypeManager.registeredTypeWidgets` (undocumented; read from the 1.13.7 source).
