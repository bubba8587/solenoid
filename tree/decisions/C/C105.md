## Decision

An AI provider's API key is stored only in this browser or app on this device. It is never saved into a document, in any form, and never sent anywhere but to the provider itself.

## Why

Documents get shared, opened elsewhere and committed to a vault, so a key inside one would leak to everyone who sees it.

## Consequences

- A document that needs AI on another machine uses that machine's own key.
- **Reopen if:** a team key store exists (then the key comes from that store, still never from the document).
