## Decision

An AI provider's API key is stored only in this browser or app on this device. It is never saved into a document, in any form, and never sent anywhere but to the provider itself.

## Why

A document gets shared, opened elsewhere and committed to a vault, and a key inside it would leak the moment any of that happened. [[B13]] aiInScope puts an AI edit on the same governed path as a human's, and a credential is not document content.

## Consequences

- A document that needs AI on another machine asks that machine for its own key; there is no "key travels with the file" path to add.
- **Reopen if:** a team key store exists (then the seam is a provider, still not the document).
