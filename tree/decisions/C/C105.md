## Decision

An AI provider's API key stays on this device. It is never saved into a document in any form, and never sent anywhere but to the provider.

## Why

Documents get shared and committed to vaults, so a key inside one would leak to everyone who sees it.

## Consequences

- **Reopen if:** a team key store exists; the key then comes from that store, still never from the document.
