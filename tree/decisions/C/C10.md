## Decision

A value never changes kind on its own; that takes a Cast node, except between true/false and numbers. A value always fits where a bigger shape is expected, and a smaller shape takes a node that picks what to keep.

## Why

A value's kind and shape are part of what it is, so neither changes quietly. Growing a shape loses nothing; shrinking one has to drop something.

## Consequences

- How it's built: [[socket-lattice]].
- **Reopen if:** a new kind of value, or a second automatic crossing between kinds.

## Contest

### Contest 2026-09-26 by claude: keep wins

keep: kinds never mix and shapes widen only upward is B17 applied to connections; both rules are cheap and derivable. opposite (automatic kind crossings, or narrowing) converts behind the user's back, which B17 forbids. deletion leaves every connection pair to be hand-listed, which B17's 'nothing converted silently' cannot decide pair by pair. Keep.
