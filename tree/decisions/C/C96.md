## Decision

A chart's options are typed as a short list like `marker=o; fontsize=12`, using the option names matplotlib uses (`marker`, `markersize`, `fontsize`, `linestyle` and so on), deliberately rather than names of our own. An option the app doesn't know is ignored, so the chart still draws.

## Why

People who style charts in text already know one vocabulary, and it is matplotlib's; a new one would have to be learned and documented for no gain. Ignoring unknown keys lets a string written for a newer build load on an older one.

## Consequences

- A new option takes its matplotlib name where one exists. Only a concept matplotlib lacks gets a name of our own, and the chart-figures spec lists it.
- **Reopen if:** the options move to structured fields with their own UI, which would make the string a derived view.
