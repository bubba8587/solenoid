## Decision

**MUST:** a React component never calls `node.data()`. When a component needs a value the node computes, that computation moves into a pure helper the component can call.

## Why

`data()` expects to run inside the engine, after the `coerceInputs` wrapper has coerced its inputs. Called from a component, it sees the raw inputs and can compute a different answer from the one the engine shows on the card. The model and the engine are headless and the view only renders ([[B10]] reactFlowView).
