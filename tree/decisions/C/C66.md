## Decision

Script is the one node that runs code you write. You write a JavaScript function, such as `(a, b) => a * b`, and each parameter becomes an input on the node. Whatever goes in or comes out is an ordinary Solenoid value: the result says its own type (you never declare one), a list mixing types is an error, and tables go in and out as Frames and Cubes.

## Why

Some things are easier to say in a few lines of code than in nodes or a formula, and the rest of the graph still sees only honestly typed values ([[B17]] typedValueModel). Frames and Cubes are allowed in, though a formula keeps them out, because Script is the advanced surface with no good reason for the same limit; the author's call.

## Consequences

- A script runs apart from the app and is stopped after a short time limit, so a runaway loop can't freeze the app.
- How it runs, and every shape and error: [[script-sandbox]].
- **Reopen if:** a script needs files or the network, state between runs, or a second language.
