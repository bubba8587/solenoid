## Decision

Each finding on the bleeding-edge branch is one commit that ports to a work branch by itself, marked ready or not ready. Ready means a work branch takes that commit and nothing else, with nothing to add and no check left to run: it ports onto the current base and passes the checks there, and for a platform feature, every engine Solenoid ships into, the oldest Linux WebKitGTK included, either has it or was run without it and behaves as the work branches do today. Anything else is not ready, and the finding names what it waits for.

## Why

The author judges the branch by porting from it, so a ready finding has to port as it stands; one that needs another round of checking on the work branch only moved the work there.
