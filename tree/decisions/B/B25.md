## Decision

Each finding on the bleeding-edge branch, a platform feature or a dependency fix, is marked ready or not ready to port to a work branch, and a ready mark is earned on the branch: a work branch takes the commits the finding names and nothing else, with no check left to run and nothing to add. A platform feature is ready when every engine Solenoid ships into, the oldest Linux WebKitGTK included, either has it or was run without it and behaves as the work branches do today. A dependency fix is ready when the upgrade and the fix port as one commit that was applied to the current base and passed its checks there. Anything else is not ready, and the finding names what it waits for.

## Why

The author judges the branch by porting from it, so a ready finding has to port as it stands; one that needs another round of checking on the work branch only moved the work there.
