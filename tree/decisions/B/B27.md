## Decision

What Solenoid computes answers to Excel, and where Excel is silent, to what makes the better app; never to the language a piece was first written in. Computation runs in Rust, compiled to WebAssembly, where that is reasonable; the language of the rest of the app is not fixed.

## Why

The goal is a good app for Excel users. The app was first written in TypeScript by circumstance, so what JavaScript happens to do is not a target; Excel is, and Rust in WebAssembly is fast and the same everywhere.

## Consequences

- Where Excel and JavaScript disagree, the answer is Excel's: a regular expression reads as Excel's (PCRE2) does, not as a browser's.
- A behavior that exists only because JavaScript has it is a candidate to delete, not to reproduce.
- **Reopen if:** Excel stops being the reference the people using Solenoid know.
