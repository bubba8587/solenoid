## Decision

Moving a dependency or the toolchain to its newest is not enough on its own. For each one that moves, an agent reads its release notes from the version the branch used before to the new one, and puts to use what lets the app drop code it does by hand or do clearly better, as with the newest platform features. What would change the look goes to the author instead.

## Why

A bump that only proves nothing broke leaves the new version's value unused; the branch exists to find out what the newest of everything makes possible, and the release notes are where that is written down.

- How it's done: [[branch#Working on the branch]]; the daily report lists each moved dependency and toolchain with its release notes.
