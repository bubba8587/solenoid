## Decision

Where an Excel habit doesn't fight the graph, Solenoid keeps it: answers recalculate on their own (or on F9, when switched to manual), and a typed edit takes effect on Enter or click-away, like a cell, never on each keystroke. Escape throws the draft away, and a pick made in one gesture, like a dropdown, applies at once.

## Why

People coming from Excel shouldn't have to learn a new tool from scratch, and their habits are part of that as much as the function names are. Committing every keystroke would also send half-typed values downstream as wrong answers.

## Consequences

- *Exception:* the descriptions of a formula's variables save on each keystroke; they are notes and never cause a recalculation. **Removed by:** a description ever feeding a computation.
- *Exception:* the Slider's playback speed applies on each change; it only drives the play timer. **Removed by:** speed ever feeding a computation.
- **Reopen if:** a habit fights the graph; then the graph wins, and the difference goes under [[A6]] divergeByDesign. A live-preview field, if one is wanted, previews the draft and still commits once.

## Contest

### Contest 2026-10-06 by Claude Opus 5.5: keep wins

Judged by A5 excelParity. Keep: A5 brings Excel users over by function names and answers; their working habits (self-updating answers, commit on Enter) are the same promise for how a sheet behaves, and the graph doesn't fight them. Opposite: new habits for the same users works against the audience A5 courts. Deletion: A5 speaks to functions and answers only, so automatic recalculation and commit-on-leave would have no parent.
