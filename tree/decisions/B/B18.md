## Decision

Opening a document someone else made is always safe: it never writes outside the app, sends anything anywhere, or carries its maker's secrets. Anything that reaches outside waits for the person who opened it to ask: a node that changes something outside the app for good, like a write to disk or to a vault, acts only when its Run button is pressed while it is armed, and it always opens disarmed. An AI provider's API key stays on this device: it is never saved into a document in any form, and never sent anywhere but to the provider.

## Why

Documents are meant to be passed around, and people would stop sharing them if opening one could write to a disk, call out or leak a key. A write that can't be undone waits for a deliberate press.

## Consequences

- *Unenforced:* a foreign document's Script nodes run without asking, and its web images load before the network gate (`docs/backlog.md` § Leaves the code breaks).
- A team key store, if one comes, supplies the key; it still never comes from the document.
- How it's built: [[node-classes]] (the Run button).
- **Reopen if:** never; loosening it would make every shared document suspect.
