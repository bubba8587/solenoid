## Decision

Solenoid does not reinvent the spreadsheet function vocabulary. Excel functions keep their Excel name and return Excel's answer. We also use other libraries' functions and behavior verbatim where possible (`pandas`, `scipy`, etc.).

1. Deprecated Excel functions are omitted (and the user is redirected to the superseding function).
2. Cell-grid-only functions (ADDRESS, INDIRECT and their kind) are omitted.
3. When Solenoid adds its own custom functions, we attempt to use or replicate Excel's syntax and behavior.

## Why

The project author, and the target customer base, are Excel users. We want to build a product that is more powerful and flexible than Excel for many workflows, but without making users learn an entire new syntax if we can help it.

## Consequences

- Any differences from Excel, including deprecations and supersedings, are carefully documented.
