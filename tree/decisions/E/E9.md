## Decision

**MUST:** an error is tagged with the node that created it, an untagged error arriving on an input is tagged with that input, and an origin already set is never overwritten downstream.

## Why

An error is only useful if the user can find where it started. Overwriting the origin downstream points them at a node that merely passed it along.
