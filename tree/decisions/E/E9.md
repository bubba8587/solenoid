## Decision

**MUST:**
- Every error records the node where it started.
- An error can reach a node with no such record: an error value read from a file, for example, or one passed along by a node that doesn't record errors. The first node that receives it records itself as the start, together with the input it came in on, so the trail still ends at a node the user can see.
- Once recorded, the start never changes as the error flows further downstream.

## Why

An error is only useful if the user can find where it started. If each node along the way overwrote the start, the error would point at the last node that merely passed it along.
