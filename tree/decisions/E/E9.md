## Decision

**MUST:**
- Every error records the node where it started.
- If an error has no traceable source node, it is tagged with the first node where it shows up.
- Once recorded, the start never changes as the error flows further downstream.

## Why

[[D35]] errorInErrorOut passes an error along unchanged so its cause stays visible downstream. That only helps if the user can find where it started: if each node along the way overwrote the start, the error would point at the last node that merely passed it along.
