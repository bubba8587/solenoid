## Decision

**MUST:** every `MutableSocket` or `AdoptiveSocket` port gets its own fresh instance, never a shared module-level one. The `staticTrueAny*` / `trueAnySocket` singleton is outside this rule: it is a plain immutable `SolenoidSocket`, not a `MutableSocket`, so the sweep never sees it.

## Why

A shared mutable socket means wiring a date into one card retypes another card's port. That port then coerces its input under the wrong type and answers a believable number the user can't trace to a cause. The Input Switch's shared `valueSocket` did exactly this.
