## Decision

`anydata` is the wildcard for a socket that takes a scalar, a list or a matrix of any element type and passes it on exactly as it arrived. It is the socket every formula variable uses.

**MUST:**
- **As an input,** `anydata` accepts every value of rank 2 or less (scalar, list, combo, matrix) and the smaller wildcards (`any`, `anylist`, `anycombo`, `anytable`). It refuses Frames, Cubes and the special objects (lambda, chart, document).
- **It never changes what it is given.** A scalar stays a scalar and a list stays a list.
- **As an output,** it connects wherever `anycombo` does; its actual shape is known only at run time, with the same accepted risk.
- Its edges are derived additions to `accepts()` under [[D14]] derivedSocketTypes, swept by the full lattice test.
- A formula surface's variable and side sockets are `anydata`: Expression variables, and Computed Column side inputs (a side value can be a whole list, as in `SUM(list)`, or a row-aligned list read with `@name`).
- The result socket keeps its family instead. The `resultAs` combo socket serves results of rank 1 or less. When a result is a matrix, the node swaps its result socket to the same family's matrix socket and reconciles through `retypeOutputCables` ([[D16]] retypeReconciles), the machinery every in-place retype uses. Downstream Format Controllers keep their family, and the socket never lies about rank.

## Why

The two neighboring wildcards each fail a formula variable:

- **`trueany`** accepts every socket type and doesn't change its input; it exists to carry a value to another place unchanged. It also accepts Frames, Cubes and special objects, which must never enter a formula ([[C15]] matricesInFormulas).
- **`anytable`** (Any Matrix) turns every scalar or list wired into it into a matrix, so a variable would see `5` as a 1×1 matrix. That breaks the many functions that expect a scalar or a list, and changes every downstream type's rank.

So `anydata` exists to be a socket that doesn't change its input and still excludes Frames, Cubes and special objects. `anycombo` can't do it either, because it refuses the matrices [[C15]] admits.

The result socket isn't `anydata`, because that would give up the family Format Controllers key on (`familyOf` is none) in exchange for a rank the matrix sockets already spell.
