On your desktop

The desktop app runs the same Rust engine as the web build, so a table gives the same answer in both. It adds the files on your disk and your Obsidian vaults.

Download for Linux

What the desktop build adds

  • Obsidian vaults. Point Solenoid at a vault folder to import and write notes directly to it.
  • Local files. Read a CSV or Parquet file from disk and write a table back out for Excel to open.

    • Build from source

    The web build needs only Node 20 and up. The desktop build additionally needs the Rust toolchain and Tauri's platform prerequisites. It builds on Windows and Linux.
