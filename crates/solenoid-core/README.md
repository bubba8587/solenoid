# solenoid-core

The Rust core: Solenoid's relational verbs, PIVOTBY and computed-column formulas, ported from the TypeScript and built
for WebAssembly (`npm run build:wasm`) and native tests (`npm run test:core`).

How it works, what it carries, the checks that hold it to the TypeScript and the rebase routine:
`tree/specs/computation/rust-core.md`.
